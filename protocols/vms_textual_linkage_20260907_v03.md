# VMS pure-text linkage v0.3 — rare ordered-sequence excess

Protocol ID: `vms_textual_linkage_20260907_v03`
Frozen: 2026-09-07

## Scope / prior failures

- RGB stain/image evidence is excluded completely.
- v0.1 generic bifolium TAIL→HEAD connection failed canonical Caesar known-order calibration (combined recall .114; false-edge .791).
- v0.2 generic local-continuity kernel failed even within known Voynich paragraph order (AUC .533–.551; 0/4 transcriptions qualified).
- Therefore no generic smoothness/similarity metric may be added or retuned in v0.3.
- Prior self-citation/copy-mutate/ED1 work is mechanism testing. v0.3 asks a different, narrower question: whether two physical text units share unusually specific ORDERED token sequences beyond what their shared unigram repertoire predicts.

## Claim vocabulary

`TEXTUAL_LINK`: A and B share more rare ordered token sequences than expected after preserving each unit's exact words and line lengths but destroying within-line token order.

A textual link does NOT imply physical adjacency, original order, chronology, copying direction, common exemplar, or semantics. Those require separate evidence.

## Representation

Four frozen IVTFF transcriptions independently: ZL, RF, IT, GC, existing SHA-256 verification.

Only word n-grams wholly contained inside a transcribed line are admitted. No sequence crossing a line, page, folio, bifolium, or current binding boundary is allowed.

For every folio / bifolium:
- exact word bigrams;
- exact word trigrams.

Global document frequency `df` is counted over complete physical bifolia for target-scale scoring and over folios for the folio known-answer calibration. Retain:
- bigram df 2–5;
- trigram df 2–5.

Weight motif m by `idf(m)=log((N+1)/(df(m)+0.5))`.

Pair score:
`S(A,B)=sum_idf(shared rare bigrams) + 2*sum_idf(shared rare trigrams)`.
The trigram multiplier 2 is frozen before target opening.

## Exact-unigram permutation null

For every evaluated pair A,B, independently permute token order WITHIN EACH ORIGINAL LINE in both units. This preserves:
- every token and token count;
- line lengths;
- unit length;
- page/folio/bifolium membership;
- broad vocabulary overlap;
while destroying the specific ordered n-grams under test.

128 deterministic paired permutations for discovery/calibration. For any candidate with discovery z>=2, rerun 2,048 deterministic permutations for final p and null SD. The final statistic is observed S minus permutation-null mean divided by permutation-null SD.

A motif is never credited if it is generated by editorial punctuation or crosses a line boundary.

## C1 — known-answer functional-unit calibration on Voynich folios

Before cross-bifolium target scoring, test whether actual conjoint folio halves share ordered rare sequences beyond matched alternatives.

Eligible known-answer panel: complete ordinary bifolia whose two folios share the same IVTFF Currier language, hand, and broad illustration class. For each real pair, alternative folio partners are restricted to same current quire + same L/H/I stratum where a nontrivial exchange set exists. Q2 and all unresolved/negative strata remain included; do not suppress them.

Primary panel score = mean pair z across the eligible actual conjoint pairs versus the distribution obtained by exact re-pairing inside each exchange stratum. Report effect and null SD together.

C1 passes if, in >=3/4 transcriptions:
- actual conjoint mean ordered-link score is >=2 matched re-pairing null SD above alternatives;
- permutation-enrichment mean z >0 and >=75% of contributing actual pairs have positive z;
- exact re-pairing p<=.01 where exhaustive enumeration is possible or empirical p<=.01 otherwise.

This qualifies sensitivity to a known functional relationship, not cross-bifolium adjacency.

## C2 — historical conventional-quire specificity control

Use frozen Aberdeen Bestiary MS 24 quires M and N (ff.80–95) at folio level. True conventional conjoint folio pairs are compared with all within-quire perfect matchings using the identical exact-ngram score and within-line permutation logic.

C2 passes specificity if neither quire nor pooled panel shows a true-conjoint positive >=2 null SD. Mandatory wording if <2 SD: `the metric does not resolve this`.

Target cannot open unless C1 sensitivity AND C2 specificity both pass.

## T — blind cross-bifolium textual-link graph

Only if C1+C2 pass.

Eligible target nodes: complete surviving bifolia with text. Replace unit IDs by opaque IDs before scoring. Current order, folio numbers, quire, hand, Currier, section and illustration metadata are sealed during scoring.

For every unordered bifolium pair and each transcription:
1. compute S(A,B);
2. 128 within-line permutations;
3. discovery z;
4. if z>=2, run 2,048 permutations and exact empirical one-sided p.

A frozen `TEXTUAL_LINK_CANDIDATE` requires:
- final z>=2 AND p<=.01 in >=3/4 transcriptions;
- at least one exact shared trigram in >=3/4 transcriptions OR >=2 distinct exact shared bigrams in all 4;
- motif-support bootstrap >=.70 in >=3/4 (resample lines within each bifolium 1,000 times);
- leave-one-motif-out remains z>=2 in >=3/4 if >=2 motifs contribute; if a single motif supplies all support, it must be a trigram with bifolium df=2 in all 4 transcriptions and is classified `SINGLE_MOTIF_LINK`, never stronger;
- no single page surface contributes >80% of weighted motif score unless classified `PAGE_LOCAL_LINK`.

## Post-reveal confound deletion

After candidates are frozen, reveal metadata. Build matched alternative-pair nulls preserving:
- hand pair class;
- Currier pair class;
- broad section/illustration pair class;
- geometric-mean token-count decile.

A candidate must remain >=2 matched-null SD in >=3/4 transcriptions. This stage can only DELETE an edge, never create one.

Also report whether the edge was already present in the earlier metadata-residual similarity graph, but this is validation/context only and cannot promote it.

## Graph interpretation

Report:
- isolated links;
- connected components;
- motifs responsible;
- whether motif occurrences are concentrated at particular page/line positions.

Do NOT orient edges. Do NOT assemble a reading/production order. A multi-edge component is a textual linkage component only.

## Stop rules

- C1 fail => target sealed; close v0.3 negative.
- C2 fail specificity => target sealed; instrument non-specific to functional bifolium relation.
- Target no candidates => close negative; no threshold changes.
- No near-edit/ED1 motif family may be added after exact target opening. Near-exact linkage, if later justified, requires v0.4 preregistration.
- No image/physical evidence can rescue an edge.

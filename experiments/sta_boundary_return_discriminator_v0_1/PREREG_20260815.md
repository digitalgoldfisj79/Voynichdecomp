# STA boundary-template vs exact-return discriminator v0.1 — preregistration

Date frozen: 2026-08-15 (Europe/London)
Branch: `experiment/sta-boundary-return-discriminator-v0.1-20260815`
Parent: `experiment/sta-boundary-robustness-v0.1-20260815`
Status at freeze: **NO TARGET MODEL OUTPUT INSPECTED**

## 1. Binding inherited result

Canonical RF1b STA-family (`SHA-256 81c331b7d8e76761e27d350c3b37ccfbe192848e6c8a227bcb5d40fb29259b17`) established:

- exact lag-2 N0: ratio 1.180, z=3.79;
- exact lag-2 N1: ratio 1.073, z=1.77;
- exact lag-2 N3: ratio 1.047, z=0.72;
- frozen exact-edge zero-memory S2: 1.064 / 0.996 / 0.986 for N0/N1/N3 and **failed F1**.

ED1 is boundary-associated but the need for neighbour dependence was not representation-robust; directionality was representation-sensitive and long-word ED1 was underpowered. Therefore this programme fits **exact recurrence only**. ED1 is diagnostic and may not be used to tune a model.

## 2. Scientific question

Does the residual exact `A ? A` recurrence near line/segment boundaries arise from a richer line-level boundary template/state with no token-identity memory, or is an explicit boundary-local identity-return dependency required?

The experiment is a discriminator, not a generic generator search.

## 3. Corpus and representation

Primary representation: canonical RF1b **STA-family**, using exactly the parent parser:

- P0 loci only;
- `<->` drawing interruptions are hard breaks;
- valid full STA words only;
- family projection is the leading capital of each two-byte STA member;
- segments shorter than two tokens are excluded;
- section labels come from inherited `enriched_records.json` mapping only.

Primary split: five deterministic folio-held-out folds using the inherited SHA-256 folio hash. No line from a held-out folio may contribute to an emission table, template, return parameter, vocabulary estimate, or backoff table used for that fold.

Secondary representation replay: RF-member may be run after the STA-family primary adjudication using the identical folds/models/hyperparameters. It is a correlated representation robustness check, not an independent replication and cannot rescue a failed STA primary result.

## 4. Frozen boundary definition

The exact lag-2 event at start index `i` is `token[i] == token[i+2]`.

A lag-2 event is **boundary-eligible** iff:

`i < 2 OR i + 2 >= n - 2`.

This is deliberately aligned to the N1 partition: the event crosses from the frozen first-two/last-two boundary zone into the remainder or terminates in the last-two zone. All other lag-2 starts are interior and are ineligible for the explicit return operation.

## 5. Nested models

Every model receives the held-out line shape (`section`, segment length `n`, and token coordinate) but never held-out token identity.

### B0 — frozen exact-edge independent baseline

Equivalent to parent S2:

`P(token_i | section, length_bucket(n), edge_coordinate_i)`

where edge coordinate is `L0-L3`, `R0-R3`, or `M`. Tokens are independent.

### B1 — deterministic exact-length refinement

Adds exactly one variable: **exact segment length n**.

Primary emission:

`P(token_i | section, n, edge_coordinate_i)`

with frozen backoff to B0 tables. No shared line state and no neighbour/token-identity information.

### B2 — latent boundary-template model, identity-blind

Adds exactly one variable to B1: a single shared latent line template `Z`.

Primary `K=8` templates are learned from training folios only by deterministic k-modes clustering of **delexicalised boundary features** at `L0-L3/R3-R0`:

- token-length bucket: `1-2`, `3-4`, `5-6`, `7+` STA-family units;
- first STA-family sign;
- last STA-family sign;
- missing coordinate marker where the line is too short.

Forbidden clustering features:

- complete token identity;
- whether any two positions contain the same token;
- ED1/equality/lag statistics;
- held-out data.

For a held-out line, `Z` is sampled before any token is generated from training-only `P(Z | section, length_bucket)`, with section then global backoff. Conditional on Z, all tokens remain independent:

`P(token_i | Z, section, n, edge_coordinate_i)`

with deterministic backoff to less-specific Z tables and then B1/B0.

Primary K is 8. K=4 and K=12 are predeclared sensitivity diagnostics only and cannot change the primary verdict.

### B3 — minimal boundary-local exact-return model

Adds exactly one operation to B2.

For each boundary-eligible target position `j=i+2`, after the B2 emission context is fixed:

- with probability `q`, emit `token_j = token_i`;
- otherwise emit from the ordinary B2 distribution.

`q` is a **single global scalar**, constrained to `[0, 0.25]`, learned on training folds only by maximum conditional likelihood. No section-specific q, left/right q, token-specific q, ED1 mutation, lag-1 copying, or general lookback is allowed in v0.1.

If q reaches the upper bound in >=2 folds, B3 is treated as misspecified and cannot receive a positive mechanistic verdict.

### CG — global-return hostile control

Uses the same fitted return form but permits the lag-2 return at every `j>=2`, not only the frozen boundary zone. This tests whether any successful B3 result actually identifies localization rather than generic repetition.

CG is a control, not a candidate mechanism.

## 6. Held-out generation

For each model and fold:

1. fit all tables/states/parameters on the other four folio folds;
2. preserve only held-out `folio`, `section`, and segment length;
3. generate a complete synthetic held-out corpus;
4. repeat for 50 deterministic replicates/model;
5. pool the five out-of-fold pieces within each replicate before scoring.

No held-out vocabulary distribution or state sequence is reused.

## 7. Primary scoring panel

The same exact-null machinery is used on real and generated corpora.

### P1 — exact lag-2 N0 magnitude

Generated median must satisfy:

`1.13 <= E2_N0 <= 1.23`.

This band brackets the inherited 1.180 signal while clearly excluding the frozen S2 median 1.064.

### P2 — boundary attenuation

Generated median must satisfy both:

- `E2_N1 <= 1.10`;
- `E2_N3 <= 1.08`.

### P3 — boundary/interior separation

Generated median must satisfy:

`E2_N0 - E2_N3 >= 0.08`.

The inherited real gap is about 0.133.

### P4 — lag specificity hostile diagnostic

Exact-recurrence ratios at lags 1, 3, and 4 are computed under the corresponding N0 null. They are **not fitted**.

For each control lag k, a generated model must not create excess materially above the real corpus:

`generated_ratio(k) <= max(1.10, real_ratio(k) + 0.05)`.

Underproduction of an unrelated control lag does not fail the exact-lag-2 mechanism. This gate prevents broad repetition from masquerading as a lag-2 explanation.

### P5 — ED1 collateral diagnostic

ED1 is not fitted. A candidate must not create a new interior ED1 anomaly:

- generated `ED1_N3 <= max(1.08, real_ED1_N3 + 0.04)`;
- generated `ED1_N0 <= real_ED1_N0 + 0.06`.

Directionality and long-word ED1 are reported but are not gates because the parent STA experiment showed those features are representation-sensitive/underpowered.

## 8. B3 predictive identity gate

Generative signature matching is not enough to support an explicit return dependency.

For every held-out **seen-vocabulary** boundary-eligible target event, compute B2 marginal target probability `p0` using training-only tables/templates and compare:

`p_B3(y | source) = q * I[y==source] + (1-q) * p0(y)`.

Primary predictive statistic: held-out per-event log-likelihood improvement B3 minus B2.

B3 receives `RETURN_PREDICTIVE_PASS` only if:

- folio-block bootstrap (2,000 resamples) 95% CI lower bound for total per-event improvement is >0;
- at least 4/5 folds have positive mean improvement;
- q does not hit the misspecification ceiling rule above.

Events whose target token is unseen in the fold's training vocabulary are reported separately and excluded from this gate, so OOV exact repeats cannot dominate the likelihood result.

## 9. Calibration controls

### CT — synthetic template-positive control

Generate a corpus from a known K=8 shared-template process with q=0 using training-derived marginals. The pipeline must identify B2 as sufficient and the fitted B3 q must remain <=0.02.

### CR — synthetic return-positive control

Generate a matched corpus with planted boundary q=0.08. B3 must recover q within +/-0.03 and pass the predictive identity gate; B2 must fail P1 or P3.

### CN1 — N1-shuffle detector null

On 100 N1-shuffled versions of the real corpus, refit the return detector using the same folds. Median fitted q must be <=0.02 and <=5% of controls may produce a positive bootstrap identity gate. Otherwise the return detector is not calibrated and the target B3 verdict is `INSTRUMENT_FAIL`.

## 10. Adjudication hierarchy

All primary decisions use STA-family, K=8, 50 OOF replicates.

1. If calibration fails: **INSTRUMENT_FAIL**. No target mechanistic claim.
2. If B0 passes P1-P5: **BASELINE_REPRODUCES_RESIDUAL**; parent mismatch requires implementation audit.
3. Else if B1 passes P1-P5: **EXACT_LENGTH_POSITION_SUFFICIENT**. Stop; no latent or return mechanism needed.
4. Else if B2 passes P1-P5: **LATENT_BOUNDARY_TEMPLATE_SUFFICIENT**. Stop; explicit identity memory is not justified.
5. Else if B3 passes P1-P5 + predictive identity gate, and CG fails localization (P2 or P3): **MINIMAL_BOUNDARY_RETURN_SUPPORTED**.
6. If B3 passes but CG also passes P1-P5: **RETURN_LOCALIZATION_UNRESOLVED**.
7. If B3 matches generatively but fails predictive identity: **DESCRIPTIVE_RETURN_FIT_ONLY**.
8. Otherwise: **TESTED_TEMPLATE_AND_MINIMAL_RETURN_INSUFFICIENT**.

The hierarchy is binding: a more complex model cannot be preferred merely because its RMSE is lower if a simpler model already passes all gates.

## 11. Prohibited rescue moves

After target output is visible, v0.1 may not add or tune:

- K outside the predeclared sensitivity values 4/8/12;
- section-specific, side-specific, token-specific or position-specific q;
- lag-1/lag-3/lag-4 copy terms;
- ED1 mutation/copy operators;
- P70 state;
- held-out template inference from token content;
- different length bins, edge widths, folds, or pass thresholds.

Any such change requires v0.2 and a fresh freeze.

## 12. Consequences

A B2 pass would mean the surviving STA lag-2 residual does **not** require explicit token identity memory: a shared boundary regime can induce `A ? A` by concentrating compatible marginal vocabularies.

A calibrated B3-only pass would be stronger: after section, line shape, exact edge position and a latent nonlexical boundary state are accounted for, knowing the token two places earlier improves held-out prediction specifically in the boundary zone.

Neither outcome identifies language, semantics, cipher, copying intent, or a historical production method. RF/STA projections remain correlated views of the same transcription.

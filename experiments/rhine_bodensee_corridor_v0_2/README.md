# Rhine–Bodensee–Upper Rhine Corridor v0.2

This programme tests whether the Rhine–Bodensee–Upper Rhine system is a better evidenced **production ecology** for the Voynich Manuscript than matched alternatives, especially northern Italy.

It inherits the audit framework of `alpine_venetian_corridor_v0_1` but changes the primary question. It does **not** attempt to identify a literal Voynich castle, patron, author or exact place of manufacture.

## Current model under test

The working constraints, not assumed conclusions, are:

- collaborative/multiple-hand production is plausible and must be treated as a production constraint;
- fair-copy/exemplar manufacture is plausible but unproven;
- the manuscript has a substantial Germanic/trans-Alpine component and real Italian-derived learned inputs;
- a learned design authority or small directing group plausibly had access to several medical, herbal, astronomical/cosmographical and technical traditions;
- the surviving object is outwardly secular/natural-philosophical rather than devotional;
- Rosettes architecture can constrain broad visual familiarity but cannot identify a specific building under the current evidence.

## Primary evidence families

1. joint calendar orthography/geography;
2. documentary and prosopographic connectivity;
3. neutral manuscript-production ecology;
4. dated transmission of independently motivated learned source traditions.

Production codicology is a cross-cutting constraint. Architecture is exploratory only.

## Candidate corridor

Bodensee/Konstanz → Alpine Rhine → Basel/Breisgau → Strasbourg/Hagenau/Upper Alsace.

## Controls

Northern Italy; southern Germany outside the corridor; Savoy/Burgundy; east-Alpine centres.

## Status

Protocol frozen 2026-09-04. Documentary census and primary-source verification underway. No primary geographical result has yet been declared.

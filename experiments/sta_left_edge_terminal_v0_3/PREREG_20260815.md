## Purpose

This is the terminal experiment in the current STA short-range recurrence programme. It asks one remaining question only:

> Does the left-edge lag-2 exact-identity residual survive after conditioning simultaneously on each held-out line's own START/MID/END token inventories and cross-fitted exact L0/L1/L2/L3 positional preferences?

No further recurrence/copy/return programme is licensed by this experiment. Regardless of outcome, this branch closes the present mechanism chain.

## Primary event set

Use only clean left-edge lines with segment length n≥6.

Each eligible line contributes exactly two lag-2 opportunities:

- `L0→L2`: positions 0 and 2;
- `L1→L3`: positions 1 and 3.

This restriction prevents the short-line START and END zones from overlapping the primary left-edge construction.

Primary statistic: total exact-identity count across both pairs.

Frozen secondary diagnostics:

- L0→L2 count;
- L1→L3 count;
- section contributions;
- token contributions.

Secondary diagnostics have no rescue authority.

## Null X0 — inherited line-zone inventory null

## Null X1 — strongest exact-position conditional null (PRIMARY)

X1 retains the same held-out line-zone token multisets, but does not assign the START and first two MID positions uniformly.

Exact-position preferences are learned on training folios only.

### START assignment

For each training occurrence of a token in START, record whether it occupies L0 or L1.

For token `t` in section `s` and line-length bucket `b`, estimate the conditional probability of L0 versus L1 using a hierarchical beta-binomial shrinkage:

1. global token-specific L0/L1 counts are smoothed toward the corpus-wide L0 rate with prior strength 5;
2. section×length-bucket token-specific counts are smoothed toward that global token-specific rate with prior strength 20.

For a held-out line with its observed START multiset fixed, the two possible START assignments are weighted by the learned L0/L1 probabilities. If both tokens are identical there is only one assignment.

### MID L2/L3 assignment

For each training occurrence of a token in the MID zone, classify its exact left coordinate as L2, L3, or REST.

For token `t` in section `s` and line-length bucket `b`, estimate a three-category probability vector using hierarchical Dirichlet shrinkage:

1. global token-specific L2/L3/REST counts are smoothed toward corpus-wide category frequencies with prior strength 5;
2. section×length-bucket token-specific counts are smoothed toward that global token-specific vector with prior strength 20.

Conditioning on the held-out line's fixed MID multiset, an ordered pair `(a,b)` assigned to L2,L3 receives weight proportional to

`count(a) * (count(b)-1[a=b]) * theta_L2(a) * theta_L3(b)`

where `theta_Lk(t)=P(Lk|t)/P(REST|t)` with a numerical floor of 1e-9. Remaining MID tokens are REST and need not be explicitly ordered.

START and MID assignments are conditionally independent given the fixed line inventories and cross-fitted training estimates.

### Exact primary null distribution

For every held-out line, enumerate the finite X1 distribution over the number of matches among `{L0=L2, L1=L3}`, giving probabilities for 0,1,2 matches.

Convolve those per-line distributions exactly across all held-out lines. The resulting probability mass function is the primary null; no Monte Carlo approximation is required for the target p-value.

Report:

- observed total matches;
- exact-null mean and SD;
- observed/expected ratio;
- standardized z;
- exact one-sided tail probability;
- pair-specific expected and observed counts.

## Calibration before interpretation

### C0 implementation exactness

On exhaustive toy lines, enumerated assignment probabilities must sum to 1 and the dynamic-programming convolution must match brute-force enumeration to tolerance 1e-12.

### C1 negative calibration

Draw 2,000 pseudo-observations from the exact X1 null PMF. The fraction satisfying the primary positive gate below must be ≤0.02.

### C2 line-zone-preserving positive calibration

Create 30 synthetic held-out arrangements from X1. Within each line, attempt lag-2 match-increasing swaps that preserve the START and MID multisets exactly, with frozen planting probability q=0.20. No token is inserted or deleted.

Requirements:

- median successful swaps ≥20;
- ≥80% of planted corpora satisfy the primary positive gate.

If C0, C1, or C2 fails, formal verdict is `INSTRUMENT_FAIL`. The programme still closes; there is no v0.4 rescue.

## Primary positive gate

A left-edge ordering residual is supported only if all hold under X1:

1. z ≥ 2.58;
2. exact one-sided p ≤ .01;
3. observed/expected ratio ≥1.10;
4. both pair-specific residuals `obs-exp` are positive.

No generic metric, section subset, token subset, smoothing sensitivity, or post-hoc model may rescue failure.

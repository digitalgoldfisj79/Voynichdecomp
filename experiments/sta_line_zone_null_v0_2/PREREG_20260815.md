# STA within-line / within-zone short-lag discriminator v0.2 — preregistration

Date: 2026-08-15
Status: **PRE-TARGET / BINDING**
Parent: `experiment/sta-fixed-marginal-diagonal-v0.1-20260815`

## Scientific question

Does the STA-family exact-identity excess at lag 2 survive a null that preserves the **actual token inventory of each individual line and each N1 boundary zone**?

The previous fixed-marginal test showed large diagonal enrichment at lags 1–4, but the effect survived N1 destroyed-order controls. The remaining confound is therefore line-local / zone-local token inventory heterogeneity.

This experiment is a conditional randomisation test, not a generator fit and not a decipherment test.

## Frozen source and representation

- canonical RF1b STA source;
- SHA-256 `81c331b7d8e76761e27d350c3b37ccfbe192848e6c8a227bcb5d40fb29259b17`;
- RF1b P0 loci only;
- STA-family token projection exactly as in the parent experiments;
- existing parser and section metadata are reused unchanged.

Source validation must reproduce the inherited STA anchors:

- E2 N0 in [1.16, 1.20];
- E2 N1 in [1.05, 1.09];
- E2 N3 in [1.02, 1.07].

Failure => `INSTRUMENT_FAIL`.

## Frozen line-local null LZ

For each parsed line independently, preserve the token multiset in each existing N1 group exactly.

The N1 grouping is inherited unchanged:

- for n >= 5: positions `[0,1]`, `[2,...,n-3]`, `[n-2,n-1]`;
- for n < 5: first two positions and the remainder.

A null corpus is generated by independently permuting tokens **only within each line-specific N1 group**.

Therefore every permutation preserves exactly:

- folio and section;
- line length;
- each line's complete token multiset;
- each line's START-zone token multiset;
- each line's MID-zone token multiset;
- each line's END-zone token multiset;
- the number of occurrences of every token in every line-zone.

It destroys only token order inside those fixed line-zones.

No token is moved between lines or between N1 zones.

## Scored events

Exact token identity is scored simultaneously at lags 1, 2, 3 and 4.

For lag L, pair `(i, i+L)` is boundary-eligible iff:

`i < 2 OR i+L >= n-2`.

This is the same broad boundary eligibility used in v0.1.

For each lag L record:

- observed exact-match count `T_L`;
- null mean and SD from 20,000 LZ permutations;
- ratio observed/null mean;
- standardized residual `Z_L`;
- one-sided permutation p-value.

The same 20,000 null corpora are used to score all four lags jointly.

## Multiple-lag correction and lag-2 specificity

For each null permutation r, standardize its four lag counts using the frozen null mean/SD for each lag.

Define:

- `M_r = max(Z_1r, Z_2r, Z_3r, Z_4r)`;
- real `M2 = Z_2`;
- `p_maxT = (1 + #{r: M_r >= Z_2}) / (R+1)`.

Define lag-2 specificity contrast:

`C_real = Z_2 - max(Z_1, Z_3, Z_4)`.

For each permutation:

`C_r = Z_2r - max(Z_1r, Z_3r, Z_4r)`.

and

`p_specificity = (1 + #{r: C_r >= C_real}) / (R+1)`.

A **lag-2-specific sequential residual** requires all of:

1. `Z_2 >= 2.58`;
2. one-sided `p_2 <= 0.01`;
3. `p_maxT <= 0.01`;
4. `C_real >= 1.0`;
5. `p_specificity <= 0.01`.

No generic recurrence metric may rescue failure.

## Calibration / hostile controls

### C0 — exact preservation audit

On deterministic sampled lines and null shuffles, verify that every line-zone Counter is identical before and after permutation. Any failure => `INSTRUMENT_FAIL`.

### C1 — null pseudo-observations

Generate 200 independent LZ-shuffled corpora from the real line-zone inventories. Treat each as a pseudo-observed corpus and score it against an independent 20,000-permutation reference distribution.

The full lag-2-specific gate above may pass in at most 5% of the 200 null pseudo-observations.

### C2 — line-zone-preserving planted lag-2 positive

Generate 30 independent LZ-shuffled corpora. Plant lag-2 identity by **within-zone swaps only**, so every line-zone multiset remains exactly unchanged.

For a candidate lag-2 boundary pair `(i,j=i+2)` with unequal tokens, a plant operation may swap position `j` with another position `k` in the same N1 target zone carrying the source token. Candidate swaps are accepted only if:

- the target pair becomes equal;
- the line-zone multiset is unchanged by construction;
- the swap yields a positive lag-2 match-count delta;
- among eligible candidates, deterministic tie-breaking minimizes collateral change in lags 1,3,4.

Each candidate is applied with frozen probability `q=0.10`, without reusing a position in more than one planted swap.

At least 80% of the 30 planted corpora must pass the full lag-2-specific gate. Median successful swaps must be >= 10. Otherwise => `INSTRUMENT_FAIL`.

This control tests sensitivity to identity coupling that cannot be explained by changed line-zone inventories.

## Secondary diagnostics

Report, without rescue authority:

- left-boundary and right-boundary lag-2 results separately under LZ;
- section-stratified observed-minus-null residuals;
- number of lines and events contributing at each lag;
- exact identity type concentration (top repeated token identities contributing to lag-2 excess), descriptive only.

## Binding adjudication

After calibration passes:

1. If lag 2 fails any of `Z_2 >= 2.58`, `p_2 <= .01`, or `p_maxT <= .01`:
   - `LINE_ZONE_INVENTORY_SUFFICIENT_FOR_LAG2`.

2. If lag 2 survives those tests but fails `C_real >= 1.0` or `p_specificity <= .01`:
   - `SHORT_RANGE_ORDERING_RESIDUAL_NOT_LAG2_SPECIFIC`.

3. Only if all five primary gates pass:
   - `LAG2_SEQUENTIAL_RESIDUAL_SUPPORTED`.

Calibration failure always overrides target behaviour:

- `INSTRUMENT_FAIL`.

No post-target threshold changes, alternative zone definitions, token exclusions, or new coupling parameters are permitted in v0.2.

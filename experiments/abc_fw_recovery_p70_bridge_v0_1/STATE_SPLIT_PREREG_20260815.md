# P70 core-state × LAAFU discriminator — preregistered 2026-08-15

Frozen before computing any state-conditioned N1/N3 statistic.

## Status

Prospective mechanistic follow-up motivated by the ABC/FW recovery. It is **not** an independent confirmation sample because the hypothesis was generated from the same Voynich corpus.

Prior-art search: repository and Library searches found prior empty-core modelling, P70 generator work, aggregate LAAFU E2 tests, and ED1 edge/position tests, but no prior test combining exact lag-2 recurrence with P70 empty-core state under the LAAFU N1/N3 nulls.

## Inputs

- Exact P0 ZLZI line selection and tokenisation from `voynich_transcriptions_slim.json`, matching `laafu_paragraph_e2_v0_3`.
- P70 state lookup from `enriched_records.json`.
- A token spelling receives a P70 core-state label only if every occurrence of that spelling in `enriched_records.json` agrees on `empty_core`. Ambiguous spellings are unlabeled.
- Abort state-specific interpretation if <98% of P0 ZLZI token occurrences receive an unambiguous label. Report coverage regardless.

## Nulls — copied, not redesigned

Use the frozen August-13 LAAFU definitions:

- **N0:** unrestricted permutation within each line.
- **N1:** within each line, shuffle positions 0–1, positions 2…n−3, and positions n−2…n−1 separately (with the historical short-line rule for n<5).
- **N3:** the N1 permutation, but score only lag-2 starts i=2…n−5 for lines n>=7.

2000 permutations for ZLZI primary statistics, seed family 20260813 + fixed offsets. This matches the scale of the historical primary LAAFU run.

## S1 — state-conditioned exact lag-2

For each exact `A X A`, classify A as `empty_core` or `nonempty_core` from the frozen P70 lookup. Compute observed, null mean/SD, ratio and z separately under N0 whole, N1 whole and N3 interior.

Primary hypothesis generated by the recovery:

> The apparent top-20 ABA-carrier effect is a proxy for a broader empty-core structural recurrence class.

### Mechanistic decision

- **INDEPENDENT EMPTY-CORE RETURN SUPPORTED** only if empty-core E2 has ratio >=1.10 and z>=3 under **both N1 whole and N3 interior**, while state-label coverage passes.
- **POSITIONAL SCAFFOLDING SUPPORTED** if empty-core E2 is positive under N0 but either N1 or N3 has ratio <1.10 or z<2.
- Otherwise **PARTIAL / UNRESOLVED**.

Nonempty-core E2 is reported as a negative/contrast channel, not used to relax the gate.

## S2 — ED1 core-state preservation under the same conditioning

For adjacent literal ED1 pairs, classify endpoint P70 states as `both_empty`, `mixed`, `both_nonempty`. Compute N0 whole, N1 whole and N3 interior using the identical N1 shuffling groups; N3 uses adjacent-pair starts i=2…n−4 so that both endpoints remain within the historical trimmed interior (positions 2…n−3).

The recovery suggested ED1 excess is state-preserving: both-empty and both-nonempty were enriched while mixed was weak.

### Mechanistic decision

- **INTERIOR STATE-PRESERVING ED1 SUPPORTED** if under N3 at least one same-state class has ratio>=1.10 and z>=3 and the mixed class has ratio<1.10 or |z|<2.
- **BOUNDARY/POSITION COUPLED** if the N0 same-state enrichment fails that N3 gate.
- Otherwise **PARTIAL / UNRESOLVED**.

No directional copy interpretation is permitted: ABC-C already found no accretion/reduction or substitution-site direction.

## S3 — architecture consequence

Only if S1 supports independent empty-core return and S2 supports interior state-preserving ED1 should a two-kernel generator be built immediately.

- S1 negative + S2 negative: no new local kernels; model both as line-position/LAAFU-conditioned structure.
- S1 negative + S2 positive: one genuine local ED1 transition kernel plus positional recurrence/scaffolding.
- S1 positive + S2 negative: one empty-core return kernel plus boundary-coupled ED1.
- both positive: two independent local kernels.

# Data dictionary — production_localisation_v1

All fields are coded at manuscript/production-unit level unless otherwise specified. `unknown` is a legitimate value and must not be replaced by inference.

## Identity and eligibility

- `manuscript_id` — stable internal identifier, preferably ManuComp ID; otherwise institution+shelfmark slug.
- `institution` — current holding institution. Never used as production location.
- `shelfmark` — current shelfmark.
- `production_unit` — whole codex or isolated original unit/part.
- `date_start`, `date_end` — accepted production date range.
- `date_midpoint` — arithmetic midpoint.
- `production_place_raw` — catalogue wording verbatim.
- `production_region_strict` — `IT`, `DE`, `X`, or `EXCLUDED` under PREREG rules.
- `localisation_basis` — `colophon`, `catalogue_codicology`, `specialist_consensus`, `style_only`, `unknown`.
- `localisation_source_id` — foreign key to `provenance/sources.csv`.
- `material` — `parchment`, `paper`, `mixed`, `unknown`.
- `cohesive_unit` — `yes`, `no`, `uncertain`.

## A. Collation / gathering construction

- `a_dominant_bifolia_per_gathering` — integer 1–8; e.g. quaternion = 4, quinion = 5, senion = 6.
- `a_quaternion_share` — proportion of reconstructable gatherings with 4 bifolia.
- `a_quinion_share` — proportion with 5 bifolia.
- `a_senion_share` — proportion with 6 bifolia.
- `a_gathering_size_sd` — standard deviation of bifolia per reconstructable gathering.
- `a_singleton_rate` — singletons/inserts divided by extant leaves where reconstructable.
- `a_quire_signatures` — `present`, `absent`, `partial`, `unknown`.
- `a_catchwords` — `present`, `absent`, `partial`, `unknown`.
- `a_collation_confidence` — `high`, `medium`, `low`.

Coding rule: a gathering inferred only from modern foliation without codicological support is `unknown`.

## B. Page preparation and geometry

- `b_pricking` — `visible`, `not_visible`, `documented_absent`, `unknown`.
- `b_ruling` — `visible`, `not_visible`, `documented_absent`, `unknown`.
- `b_ruling_medium` — `leadpoint`, `ink`, `drypoint`, `mixed`, `other`, `unknown`.
- `b_columns` — integer number of principal text columns.
- `b_page_width_mm`, `b_page_height_mm` — current leaf dimensions; trimmed status separately coded.
- `b_page_aspect` — width / height.
- `b_textblock_width_mm`, `b_textblock_height_mm` — principal written area where measurable.
- `b_textblock_aspect` — width / height.
- `b_margin_inner_ratio`, `b_margin_outer_ratio`, `b_margin_top_ratio`, `b_margin_bottom_ratio` — margin / page dimension; measured from a representative median page, not a hand-picked page.
- `b_trimmed` — `yes`, `no`, `possible`, `unknown`.
- `b_parchment_flaw_strategy` — `avoid_text`, `write_around`, `write_over`, `mixed`, `unknown`.
- `b_hair_flesh_pattern` — free categorical value following catalogue terminology plus standardised field `b_hair_flesh_regular` = `yes/no/unknown`.

## C. Production sequence

- `c_image_text_sequence` — `text_first`, `image_first`, `preplanned_reserved_space`, `mixed`, `unknown`.
- `c_text_wraps_image` — `frequent`, `occasional`, `absent`, `unknown`.
- `c_reserved_image_blanks` — count of clearly intended but unexecuted image spaces; `unknown` if not systematically observable.
- `c_image_text_collisions` — `frequent`, `occasional`, `absent`, `unknown`.
- `c_underdrawing_relation` — `under_text`, `over_text`, `mixed`, `none_seen`, `unknown`.
- `c_sequence_confidence` — `high`, `medium`, `low`.

## D. Scribal micro-practice

Measurements should use a deterministic page sample generated by `scripts/freeze_page_sample.py`; no visually convenient page selection.

- `d_line_spacing_norm` — median baseline-to-baseline distance / page height.
- `d_baseline_drift_norm` — median absolute fitted baseline slope expressed as vertical displacement / line width.
- `d_left_margin_sd_norm` — SD of line starts / page width.
- `d_right_margin_sd_norm` — SD of line ends / page width.
- `d_line_final_compression_rate` — proportion of sampled lines showing compressed final spacing relative to line median.
- `d_paragraph_indent_median_norm` — median first-line indentation / textblock width.
- `d_correction_density` — corrections per 1,000 visible written characters/marks where character counting is meaningful; otherwise `unknown`.
- `d_nib_width_norm` — median estimated stroke width / page width.
- `d_measurement_method` — script/version identifier used.

These features intentionally do not identify characters, languages, glyphs, or abbreviation systems.

## E. Collaborative production structure

- `e_secure_hand_count` — integer, or `unknown`.
- `e_hand_allocation` — `single_hand`, `sequential_pages`, `sequential_gatherings`, `nested_bifolia`, `mixed`, `unknown`.
- `e_bifolium_allocation` — `yes`, `no`, `possible`, `unknown`.
- `e_hand_source_id` — source supporting hand distinction/allocation.
- `e_hand_confidence` — `high`, `medium`, `low`.

## Provenance requirements

Every non-derived value must have at least one row in `data/feature_sources.csv` containing:

- manuscript_id
- field
- value
- source_id
- source_locator (page/folio/line/catalogue field)
- source_quote_or_observation
- coder
- coded_at_utc
- confidence
- image_asset_id if image-derived

Derived numeric values must identify the script and input asset IDs that generated them.

## Controlled uncertainty

Do not use zero for unknown. Numeric unknowns are blank/NA. Categorical unknowns are literal `unknown`.

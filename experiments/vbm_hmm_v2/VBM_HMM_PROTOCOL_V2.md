# VBM v2 — Typed HMM Inference Protocol

Date: 2026-08-11
Namespace: `VBMHMMV2`
Parent closeout: `87b54965a59b0bc1c12d93c8e7311f30cde6f399`

## Motivation

VBM v1 produced a prospectively held-out C/V topology result that selected Bavarian over German and Italian, but its direct map-space annealer failed qualification because highly homophonic Bavarian controls did not converge to a unique deterministic homophone map. No typed Voynich H1 substitution fit was ever run.

v2 changes the inference family and explicitly stress-tests the unknown homophony regime before any target fit. Latent plaintext letters are inferred by a typed hidden Markov model; observed VBM units are generated by homophonic emission distributions learned with Baum–Welch/EM. The model is judged by reproducibility of posterior plaintext decoding and held-out likelihood, not uniqueness of an arbitrary homophone allocation.

## Frozen representation and data

Unchanged from VBM v1:
- 21 core surface units; core units may emit consonants only.
- 123 bridge surface units selected on FIT-A at >=0.995 occurrence coverage; bridge units may emit vowels only.
- `VR=qo` when the retained token begins `qo`; otherwise VR is the first retained character.
- VL is the final retained character.
- right-edge `eed` then `ed` are C2 composite core units; other maximal `e+` runs are composite core units.
- FIT-A = original 181 folios.
- VBM_H1 = `f28v f31v f88r f5r f34r f81v`.
- VBM_C1 = `f85r1 f53v f33r f10r f23r f111r` and remains sealed unless H1 passes all v2 candidate gates.

Language panel is fixed:
1. Bavarian (`bavarian-nlp/barwiki-20250720`) — primary hypothesis.
2. Standard German (UD German GSD) — nearest rival.
3. Italian (UD Italian ISDT) — source-native comparator.

Normalisation is unchanged: 19-letter `abcdefghilmnopqrstu`; j->i, v/w->u, y->i, x/z->s.

## Model

For each language L:
- a first-order transition matrix P_L(x_t | x_{t-1}) is the corpus-derived bigram projection of the same normalized language data used by v1;
- the original add-0.25 character trigram model is retained as an independent decoded-text score;
- each observed surface unit y_t is emitted from current hidden letter x_t with probability E_L(y_t | x_t);
- core observations have zero emission probability from vowels;
- bridge observations have zero emission probability from consonants.

EM estimates only E; language transitions remain fixed. Exact forward–backward is used over the 19 hidden letters.

### Initialization and ensembles

Fresh deterministic seeds under `VBMHMMV2`. For each candidate language and control:
- 4 random Dirichlet initializations, split into ensembles A/B (2 each);
- Dirichlet concentration 0.35 over allowed surface units;
- additive emission pseudo-count 0.05 per allowed surface/plaintext cell;
- maximum 40 EM iterations;
- stop when relative train log-likelihood improvement < 1e-7 for 3 consecutive iterations.

The best training-likelihood run per ensemble is retained.

### Posterior decoding

For fixed E, exact forward–backward gives posterior P(x_t | y,L). Decoded plaintext is posterior argmax per event.

A/B convergence on holdout requires:
- posterior decoded-letter agreement >=0.95;
- held-out HMM score gap <=0.01 nats/event;
- both retained runs satisfy the EM stop.

A hard homophone map may be reported diagnostically but map identity is not a gate.

## Q0-HS — broad homophone stress sweep

This stage is mandatory and precedes language discrimination. It addresses the fact that the 123 bridge symbols represent only five vowels, so both the number of homophones per vowel and their within-vowel usage can vary drastically.

For each language, generate one fresh 18,000-fit / 7,000-holdout control under each of **12 preregistered homophone regimes** = 36 controls total.

### Homophone-count allocation

Within consonant and vowel types separately, every plaintext letter receives at least one surface symbol. Remaining surface symbols are allocated according to six regimes:

1. `ANTI_SQRT`: weights proportional to plaintext unigram frequency^-0.5.
2. `UNIFORM`: equal weights per plaintext letter.
3. `SQRT_FREQ`: weights proportional to frequency^0.5.
4. `FREQ_PROP`: weights proportional to frequency^1.0 — classical frequency-equalising homophony.
5. `SUPER_FREQ`: weights proportional to frequency^1.5.
6. `DIRICHLET_SKEW`: fresh deterministic Dirichlet(0.20) allocation weights, multiplied by frequency^0.5 before integer apportionment.

Integer apportionment uses deterministic largest remainder after reserving one surface per letter.

### Within-letter homophone usage

Each allocation regime is crossed with two use profiles:

- `FLAT`: conditional on plaintext letter, all assigned surface homophones are equiprobable.
- `SKEW`: conditional probabilities drawn from deterministic Dirichlet(0.25) over that letter's assigned homophones.

Thus Q0-HS covers balanced, classical frequency-flattening, anti-frequency, super-frequency and strongly irregular homophony, with both even and uneven use.

Only the true-language HMM is fitted at Q0-HS. A stress control passes if:
- posterior plaintext recovery >=0.85;
- A/B posterior decoding agreement >=0.95;
- A/B HMM score gap <=0.01;
- both A/B retained EM runs converge.

Q0-HS gate:
- each language passes >=10/12 regimes;
- `UNIFORM/FLAT`, `FREQ_PROP/FLAT`, `FREQ_PROP/SKEW`, and `DIRICHLET_SKEW/SKEW` must pass for all three languages;
- median recovery across all 36 >=0.95;
- no recovery <0.80.

Failure stops v2 before language-selection qualification. No target is scored.

## Q1 — language-specific positive controls

Only if Q0-HS passes.

Use four anchor homophone regimes spanning the stress envelope:
1. `UNIFORM/FLAT`;
2. `FREQ_PROP/FLAT`;
3. `FREQ_PROP/SKEW`;
4. `DIRICHLET_SKEW/SKEW`.

For each language and anchor, generate a fresh 30,000-fit / 12,000-holdout control under a new Q1 key: 12 controls total. Fit all three candidate language HMMs.

A control qualifies only if:
- correct language ranks first on fixed-emission holdout HMM likelihood;
- margin over runner-up >=0.02 nats/event;
- correct-language posterior plaintext recovery >=0.90;
- A/B posterior decoding agreement >=0.95;
- A/B HMM score gap <=0.01;
- both A/B runs converge;
- correct-language posterior-decoded trigram score beats the two wrong-language posterior decodings.

Q1 gate:
- 12/12 correct language rank1;
- >=11/12 controls individually qualify;
- each language >=3/4 individually qualify;
- all four Bavarian anchors rank Bavarian first;
- median plaintext recovery >=0.95;
- minimum recovery >=0.90.

Language-specific absolute H1 floor = 5th percentile of the four correct-language Q1 holdout HMM scores.

## Q2 — structured negatives

Only if Q1 passes.

40 negatives: 8 each IID, order-2 permuted Markov, motif, copy/mutate, slot grammar. Each preserves typed core/bridge status and approximately the FIT-A surface-frequency profile but has no natural plaintext.

Each negative is fit under all three language HMMs. It is a false positive only if:
- selected language score >= that language's Q1 floor;
- selected-over-runner-up HMM margin >=0.02;
- A/B posterior decoding agreement >=0.95;
- A/B score gap <=0.01;
- both ensembles converge.

Q2 gate: <=1/40 total false positives and <=1 for any generator class.

## H1 target

Only if Q0-HS, Q1 and Q2 all pass.

For each language:
- fit E on FIT-A only;
- score and posterior-decode VBM_H1 without refitting;
- retain A/B independent estimates.

A language is an H1 candidate only if:
- H1 HMM score >= its frozen Q1 absolute floor;
- A/B H1 score gap <=0.01;
- A/B posterior decoded-letter agreement >=0.95;
- both ensembles converge;
- it ranks first on H1 with HMM margin >=0.02 nats/event;
- its posterior-decoded text also ranks first under the independent trigram score.

Primary Bavarian candidate additionally requires Bavarian rank1.

If no language passes: no C1.
If a candidate passes: open VBM_C1 once and apply the already fitted A/B emissions without refitting. Confirmation requires the same absolute floor, A/B, HMM-rank and decoded-trigram-rank gates on C1.

## Stop rules

- No changing VBM unitisation, bridge vocabulary, language panel, homophone sweep, smoothing, starts, EM threshold, or candidate gates after Q0-HS begins.
- If Q0-HS fails, Q1/H1 are not scored.
- If Q1 fails, Q2/H1 are not scored.
- If Q2 fails, H1 is not scored.
- If H1 fails, VBM_C1 remains sealed.
- v3 requires another materially new inference family, not more EM starts/iterations or a narrower homophone regime selected post hoc.

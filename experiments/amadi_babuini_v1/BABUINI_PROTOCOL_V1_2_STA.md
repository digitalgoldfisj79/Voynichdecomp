## 1. Scientific question

Test the narrow, source-supported Amadi core Babuini architecture as a one-visible-sign mixed letter/syllable cipher, without reconstructing compound signs from RF character adjacency.

Source basis preserved from the supplied Amadi/Scheers analysis:

- the core table assigns a unique sign to each consonant+vowel syllable;
- a separate transposition alphabet supplies ordinary single-letter signs;
- the later solved Babuini table again contains all CV syllables, with `qua/que` as exceptional three-letter syllables;
- the 61 signs counted in one solved ciphertext are signs *used in that ciphertext*, not the complete codebook;
- sections 386–389's 1,365-combination syllabary is a separate broader residual and is not silently folded into this core test.

## 2. Superseded engineering attempts

No Voynich holdout was scored in either attempt.

### v1 61-used-sign model

Aborted after the source audit showed that 61 was an observed-message inventory, not the underlying codebook size. Its 14-letter+47-syllable approximation also covered only ~72–75% of normalized Italian characters.

### v1.1 RF adjacent-pair unitiser

A source-corrected 89-unit core inventory was built, but the proposed RF 19-singleton + 70-PMI-pair unitiser recovered only ~5% of hidden Babuini units on synthetic controls and did not converge. It is `CALIBRATION_BLOCKED` and is not used below.

## 3. Frozen Babuini plaintext units

Historical normalization alphabet: `abcdefghilmnopqrstu`.

The normalized core inventory contains exactly 89 units:

1. 19 single letters;
2. 70 consonant+vowel units, with q represented as `qua, que, qui, quo, quu`.

Plaintext segmentation is deterministic and source-close:

1. consume q-u-V as one unit where present;
2. otherwise consume C-V as one unit;
3. otherwise consume one ordinary letter.

There is no optional `p_syll` nuisance parameter. This distinguishes the Amadi core test from Tranchedino v2.4 B1-O1, whose registered family failed because its source allowed sparse optional syllabary use. The previous Tranchedino controls showed near-exact recovery in the high/obligatory-syllabary strata; this programme tests the deterministic Amadi case prospectively.

## 5. Solver

Each representation sign maps bijectively to one of the 89 frozen Babuini plaintext units.

Language scoring: word-sensitive trigram model over deterministic Babuini units, trained only on the inherited Italian training partition.

Formal optimizer:

- 100,000 legal swap proposals per restart;
- two independent ensembles A/B;
- batches of six restarts;
- maximum 24 restarts per ensemble;
- stop only when A/B objective difference <= 1e-7 nats/unit and frequency-weighted map agreement >= 0.95.

## 7. Formal qualification

Fresh namespace: `AMADIBABUINISTAV1Q1`.

Positive controls:

- 12 independent controls;
- each has 18,000 Babuini units fitting + 18,000 disjoint held-out units;
- independent random 89x89 hidden bijection per control;
- no true map is supplied to the optimizer.

Binding positive gates:

- median held-out unit recovery >= 0.95;
- minimum held-out unit recovery >= 0.85;
- all 12 controls converge;
- minimum A/B weighted map agreement >= 0.90.

Absolute natural-message score floor = 5th percentile of the 12 held-out positive-control scores.

Specificity panel:

- 60 structured negatives;
- 12 each: iid, bounded Markov, motif-repeat/mutate, copy/mutate, slot grammar;
- at most 2/60 may reach the absolute positive floor.

Any failed gate => `CALIBRATION_BLOCKED`, and no Voynich BAB_H1 score is permitted.

## 8. Target split and sealing

FIT-A is inherited unchanged from Amadi Residuals v1: 181 folios used for fitting and representation-vocabulary selection.

The previously untouched 23-folio Amadi C2 is hash-sorted under the frozen namespace `AMADIBABUINISTAV1DEVsplit::<folio>` and split:

- `BAB_H1`: first 11 folios;
- `BAB_C1`: remaining 12 folios.

Only folio identities are frozen before qualification. BAB_C1 representation content, coverage, scores and plaintext remain unread until formally unlocked.

## 9. H1 adjudication

Only after formal qualification passes:

For full STA and connected aaa separately:

1. use the 89-sign FIT-A vocabulary frozen in the manifest;
2. require BAB_H1 whole-word character coverage >= 0.995;
3. fit the 89x89 map on FIT-A only;
4. require optimizer convergence;
5. score the fixed map on BAB_H1;
6. compare to the frozen absolute positive-control floor.

Verdicts per representation:

- representation coverage <0.995 => `SURFACE_INCOMPATIBLE`;
- optimizer nonconvergence => `UNRESOLVED_SEARCH`, regardless of H1 score;
- converged + below floor => `CLOSED_NEGATIVE`;
- converged + at/above floor => `BAB_H1_CANDIDATE`.

A programme-level candidate requires **both full STA and connected aaa** to be `BAB_H1_CANDIDATE`. This is deliberately conservative against representation artefacts.

Only then may a separately frozen source-narrowing/replication stage inspect BAB_C1. H1 plaintext is not to be inspected merely because a score is high.

## 10. Scope of result

This programme tests deterministic core CV Babuini under an 89-sign normalized architecture. It does not close or confirm:

- the separate 1,365-combination expanded syllabary;
- nomenclator/whole-word entries not independently fixed;
- arbitrary many-to-one glyph collapses;
- optional syllabary schedules;
- post-hoc mixed mechanisms.

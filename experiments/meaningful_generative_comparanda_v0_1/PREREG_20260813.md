# Meaningful generative comparanda v0.1 — preregistration

Date frozen: 2026-08-13
Branch: `experiment/meaningful-generative-comparanda-v0.1-20260813`

## Motivation

The preceding joint-lag programme left two observations requiring harder interpretation:

1. exact lag-2 recurrence in Voynich standard paragraph text is largely demoted by explicit line-position/LAAFU conditioning;
2. the strongest surviving local statistic is adjacent **non-identical literal character Levenshtein distance 1** (`ED1`), which is also robustly produced by the explicit adjacent derivative (`reuse_last`) branch in the published Timm–Schinner generator.

The scientific question is no longer whether these surface phenomena exist. It is whether their joint statistical phenotype is specific to semantically empty generation / ciphertext, or is also found in independently meaningful, historically attested **formulaic or generative production systems**.

This experiment therefore compares Voynich against corpora chosen *without reference to their target scores*.

## Frozen corpora

### VMS-P0 — Voynich standard paragraph text

- ZLZI transcription content.
- VTC locus subtype exactly `P0`, as in the completed LAAFU v0.3 programme.
- Existing frozen corpus size: 3,885 loci; 33,200 tokens.
- Existing untouched targets used without recomputation where available:
  - ED1 N0 ratio 1.16338, z +5.994;
  - exact adjacent E1 N0 ratio 1.01819, z +0.350;
  - exact lag-2 E2 N0 ratio 1.21730, z +3.740;
  - E2 boundary-class N1 ratio 1.08033, z +1.571;
  - E2 trimmed-interior N3 ratio 1.06453, z +0.889.
- **New frozen target, not inspected before this preregistration:** ED1 under N1 and N3 positional conditioning.

### LLCT1 — Late Latin Charter Treebank 1 v1.2

- Source: Timo Korkiakangas, Zenodo DOI `10.5281/zenodo.3633607`.
- Early Medieval Latin original charters, Italy, AD 714–869, PML/XML.
- Use the corpus authors' **sentence-level formulaic/free annotation**; no automatic formula detector and no manual relabelling.
- This is the primary external textual comparandum because formulaic and free material occur inside the same documentary tradition.
- Diplomatic/surface word form is primary. Unicode NFC + lowercase only. A node is a lexical token iff its author-provided surface form contains at least one Unicode letter. Punctuation-only/editorial-only nodes are excluded.
- Sentence order and charter membership are preserved from the corpus metadata.

### CANTUS-v0.2 — CantusCorpus v0.2

- Source: `bacor/cantuscorpus`, release `v0.2`, published 2020-07-31.
- Medieval plainchant melodies with Volpiano transcriptions derived from the Cantus Database.
- This is a **structural-symbolic analogue**, not a text corpus. It will not be coerced into the Voynich token metrics.
- Only chants whose Volpiano transcription parses successfully and contains at least 20 pitched notes are eligible.

### RIDGES Herbology

- The public RIDGES documentation establishes relevant late-medieval/early-print German herbal witnesses including *Das Buch der Natur* (Augsburg 1482) and *Gart der Gesundheit* (Ulm 1487), with diplomatic transcription and line-break annotation.
- Because current automated access to the downloadable corpus is protected by the host and the project Git repository requires account access, RIDGES is **predeclared as an optional robustness corpus only if the released bytes can be obtained without bypassing access controls**. Failure to obtain it is not grounds to substitute another corpus post hoc.

### Excluded corpora

- Middle English Medical Texts (MEMT): relevant, but commercially distributed rather than openly downloadable.
- Corpus of Early English Recipes (CoER): relevant, but publicly listed as not yet available.
- No Voynich-adjacent corpus or theory-specific generator may be added after target inspection in v0.1.

## Text statistic definitions

For a locus/sentence token sequence `x[0..n-1]`:

- `E1 = sum_i 1[x_i == x_{i+1}]`.
- `ED1 = sum_i 1[x_i != x_{i+1} AND Levenshtein_char(x_i,x_{i+1}) == 1]`.
- `E2 = sum_i 1[x_i == x_{i+2}]`.

Levenshtein is literal Unicode-character edit distance after the corpus-specific normalization frozen above. No linguistic stemming, phonological mapping, abbreviation expansion, or glyph-family mapping is allowed.

## Positional nulls

All nulls preserve the exact token multiset of each locus/sentence.

- `N0`: uniform shuffle over all positions within the locus.
- `N1`: shuffle only within three sharp boundary classes: FIRST2 positions 0–1; INTERIOR; LAST2 positions n-2..n-1.
- `N3-ED1`: evaluate only adjacency starts `i >= 2` with `i+1 <= n-3`, under N1.
- `N3-E2`: evaluate only lag-2 starts `i >= 2` with `i+2 <= n-3`, under N1.

Aggregate Monte Carlo: 1,000 permutations for VMS P0 new targets; 500 permutations for each LLCT primary group/null. Fixed seed `20260813`. Null mean is also checked against the exact combinatorial expectation where implemented.

## Controls

### C0 null calibration

For each new statistic/null implementation, create 20 pseudo-corpora by one fresh draw from that null and score each against 200 fresh null draws.

PASS iff:
- mean ratio in [0.95, 1.05], and
- no more than 2/20 pseudo-corpora have |z| >= 2.

If a control narrowly fails, a calibration-only extension may be frozen after the run exactly as in LAAFU v0.3, but it cannot change the literal preregistered verdict.

### C1 ED1 known-answer control

Starting from an N1-shuffled corpus, inject non-overlapping wholly-interior adjacent ED1 pairs into 2% of eligible loci by changing the second member to a literal one-character mutation of the first. The changed multiset is then held fixed by the null.

PASS iff ED1 N3 ratio >= 1.15 and z >= 3.

## Primary hypotheses

### H1 — VMS ED1 is independent of LAAFU

`STRONG SUPPORT` iff both new P0 targets satisfy:
- N1 ED1 ratio >= 1.10 and z >= 3; and
- N3 ED1 ratio >= 1.10 and z >= 3.

`PARTIAL` iff exactly one does.

Otherwise `UNSUPPORTED`.

This is intentionally the same hard demolition logic used for E2.

### H2 — meaningful formulaic Latin exhibits a VMS-like local-order phenotype

For LLCT1 formulaic (`F`) and free (`R`) sentences compute the vector

`P = [log ED1_N0, log ED1_N1, log ED1_N3, log E1_N0, log E2_N0, log E2_N1, log E2_N3]`.

For VMS, use the corresponding frozen/new P0 ratios. Define unweighted Euclidean distance in this seven-dimensional log-ratio space:

`d_F = ||P_VMS - P_LLCT_F||`, `d_R = ||P_VMS - P_LLCT_R||`.

Use 1,000 charter-block bootstrap resamples of LLCT1 to quantify `d_F/d_R`.

`SUPPORT` iff:
- point estimate `d_F <= 0.90*d_R`, and
- `d_F < d_R` in >=95% of bootstrap resamples.

`OPPOSITE` iff the reverse symmetric criterion holds for free text.

Otherwise `UNRESOLVED`.

This criterion does **not** require formulaic Latin to reproduce Voynich exactly. It tests the narrower claim that the VMS local-order phenotype lies closer to an independently meaningful formulaic production regime than to freer prose in the same historical corpus.

### H3 — formulaicity specifically increases copy/variation adjacency

Primary effect is

`Delta_ED1 = log(ED1_N0_F) - log(ED1_N0_R)`.

`SUPPORT` iff Delta_ED1 > 0 and the 95% charter-block bootstrap CI excludes 0.

This is separate from H2: a formulaic corpus might resemble VMS for other components even if ED1 itself is not enhanced.

## Secondary LLCT analyses (frozen, not used to rescue H2/H3)

- N0→N1 and N1→N3 attenuation for ED1 and E2.
- Sentence-length strata 5–9, 10–14, 15–24, >=25.
- Surface-form primary versus author-provided lemma robustness, if lemma is available without reconstruction.
- Formulaic/free token counts and vocabulary/type-token diagnostics.

No section, date, scribe, charter type, or lexical-family subgroup may be promoted to a positive headline based on this v0.1 run.

## Chant structural analogue

The chant tier tests only the general mechanism suggested by the literature: meaningful formulaic systems can place a restricted reusable vocabulary at unit boundaries.

### Representation

- Parse Volpiano using the published `chant21` tooling where possible.
- Convert each pitched-note melody to a sequence of successive **diatonic pitch intervals**. This removes absolute pitch while retaining melodic movement.
- Build fixed 4-interval windows (5 notes). No learned or hand-selected phrase segmentation.

### Position classes

For each eligible chant:
- START = first 3 windows;
- END = last 3 windows;
- INTERIOR = all other windows excluding two-window buffers adjacent to START/END.

Analyses are stratified by mode when mode metadata is available.

### Metrics

Within each mode:
1. Shannon entropy of 4-interval-window type distribution by position class.
2. repeat fraction: fraction of windows whose exact type occurs >=5 times in that mode corpus.
3. top-1% concentration: mass held by the most frequent 1% of window types.

For START and END separately, draw 1,000 size-matched random samples from INTERIOR windows within the same mode. Aggregate mode-level standardized effects by equal weighting across modes with >=100 eligible chants.

### H4 — chant boundary formulaicity

`SUPPORT` iff BOTH START and END show, relative to matched interiors:
- lower entropy in >=6/8 canonical modes (or >=75% of eligible modes if fewer than 8); and
- higher repeat fraction in the same directional threshold.

Top-1% concentration is confirmatory/descriptive only.

This result is an analogy about production architecture, **not** evidence that Voynich encodes music or chant.

## Interpretation rules

1. A VMS-like result in meaningful formulaic corpora weakens the inference `surface generation => semantic emptiness`; it does not establish a specific historical source.
2. Failure of LLCT/chant to resemble VMS strengthens neither a cipher nor a hoax conclusion by itself; it only rejects these particular comparanda.
3. Cross-language literal ED1 is representation-sensitive. Similarity in ratio is a statistical phenotype, not glyph or morpheme identity.
4. No result may be described as proof of `generated`, `encoded`, `meaningful`, or `meaningless` text.
5. RIDGES may only be added if its released corpus is obtained through normal public access; no access-control bypass.
6. All negative and implementation-failure results are retained.

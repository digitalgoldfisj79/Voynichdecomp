# HARD NEGATIVES — f57v Wind Iconography v0.2
Date: 2026-08-09

Purpose: test whether the morphology currently making f57v look wind-compatible is actually wind-specific. This note deliberately prioritizes counterexamples.

## HN1 — `Speculum virginum`, Mystical Paradise: strongest discovered confound

### Troyes, Médiathèque Jacques-Chirac MS 252, f.14, ca.1195–1205
Biblissima/Initiale provides an unusually precise description of this non-wind diagram:
- radiant / radial composition;
- a central Christ bust over a crowned female figure (probably Ecclesia);
- on the horizontal and vertical axes, **four male personifications of the rivers of Paradise**;
- each of those four figures **holds two medallions** containing an Evangelist symbol and a Father of the Church;
- diagonal structures carry the four cardinal virtues and eight Beatitudes.

This is a very serious morphological control because it independently instantiates much of the geometry that initially made the wind hypothesis attractive:

`central object/body + four axial anthropomorphs + outstretched/active hands + two small round objects per principal figure + radial four/eight organization`.

It is **not a wind diagram**.

### Interpretation
This does not simply falsify the wind hypothesis, because Raff explicitly notes iconographic traffic between wind tables and Paradise-river imagery. In particular, he argues that some four-river arrangements look derived from principal/collateral wind schemes. Therefore HN1 shows two things simultaneously:

1. the conjunction `four axial figures + two held round objects each` is **not semantically unique to winds**;
2. the same graphical grammar can migrate between semantic domains, which supports a transformed/shared-template model.

For f57v this means the claim must be weakened from `this morphology diagnoses winds` to `this morphology belongs to a medieval fourfold cosmological/allegorical diagram grammar in which wind diagrams are a major documented member`.

## HN2 — Four elements, circular scientific diagram, ca.1350

Paris, Bibliothèque Sainte-Geneviève MS 1029 f.130, ca.1345–1355 (Toulouse / SW France), is catalogued by Biblissima as a scientific circular representation of the **four elements**.

This confirms that circular fourfold scientific diagrams remain common in the immediate pre-Voynich period. The catalogue description does **not** establish four axial anthropomorphs or repeated hand gestures, so it is a geometry-only negative rather than a morphology-matched negative.

## HN3 — Milan cosmography, 14th century

BnF Latin 6556 f.4v, made in Milan in the 14th century, is catalogued as a cosmographic diagram integrating zodiacal signs, cardinal points, solar path and seasonal/qualitative information. Again this is a strong generic-cosmography control, but current metadata do not establish the f57v-like four-human morphology.

## HN4 — fourfold macrocosm / microcosm diagrams

The manuscript tradition also contains concentric schemes divided into four quarters that correlate cardinal points, elements, seasons and humours. These demonstrate that 4-fold + concentric geometry is intrinsically non-diagnostic.

## Revised specificity hierarchy

Features should now be weighted as follows:

### Weak / generic
- circle or concentric annuli;
- fourfold organization;
- 4/8/12 numerology by itself;
- central emblem;
- annular writing.

### Intermediate
- four anthropomorphs specifically on horizontal/vertical axes;
- repeated center-directed orientation;
- consistent arm/hand gestures at all four positions.

### Potentially strong but no longer wind-exclusive
- each of four principals manipulating two subordinate round/personified objects;
- hierarchy encoded by principal full figures versus subordinate heads/medallions.

### Strongest wind-specific features, if actually present on the target
- unambiguous breath streams;
- wind labels/names or directional semantics;
- horns/trumpets or blowing posture in a wind context;
- a verified principal/collateral 4+8 hierarchy whose subordinate objects are wind heads.

f57v currently lacks the strongest secure wind-specific features: no unambiguous breath and no securely identified held heads.

## Consequence

The current best hypothesis is **not** `f57v is proven to be a wind rota`. It is:

> f57v uses a medieval fourfold radial diagram grammar that is demonstrably used for wind/cosmographic material and also demonstrably migrates into closely related allegorical systems such as the four rivers of Paradise.

The next discriminant is therefore semantic residue in the image itself: do the four f57v figures contain mouth/breath, wind-instrument, directional, subordinate-head, or other details that select the wind branch over the Paradise-river / elemental / theological branches?

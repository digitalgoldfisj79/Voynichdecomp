# STA fixed-marginal boundary diagonal test v0.1 — preregistration

Date frozen: 2026-08-15
Branch: `experiment/sta-fixed-marginal-diagonal-v0.1-20260815`

## 1. Binding inherited result

Canonical RF1b STA-family (`SHA-256 81c331b7d8e76761e27d350c3b37ccfbe192848e6c8a227bcb5d40fb29259b17`) has a boundary-associated exact lag-2 excess:

- E2 N0 = 1.1801;
- E2 N1 = 1.0720;
- E2 N3 = 1.0484.

The prior boundary-return discriminator ended `INSTRUMENT_FAIL`. Its apparent held-out identity-predictive effect was non-specific: the return detector passed in 100% of N1-shuffled controls and 100% of template-only synthetic controls. Therefore this experiment does **not** fit a copy/return generator. It asks whether the observed `A ? A` diagonal exceeds what is forced by the two endpoint vocabularies themselves.

## 2. Scientific question

For boundary-eligible lag-2 events, after fixing the source-token multiset and target-token multiset within matched positional contexts, is exact identity (`source == target`) still enriched?

This distinguishes:

1. **shared positional inventory / mixture** — the two positions favour overlapping tokens, creating many `A ? A` events without identity coupling;
2. **identity-specific coupling** — exact same-token pairing is favoured above the amount implied by those marginals.

A positive result is evidence only for identity-specific statistical coupling. It is not, by itself, evidence of copying direction, language, semantics, cipher, or scribal intent.

## 3. Corpus and representation

Use exactly the parent RF1b STA-family parser:

- P0 loci only;
- `<->` drawing interruptions are hard breaks;
- valid full STA words only;
- STA-family token = leading capital of each two-byte STA member;
- segments shorter than two tokens excluded;
- inherited section labels only.

Validation must reproduce source SHA-256 and the inherited E2 anchor windows before target adjudication.

## 4. Frozen event definition

For a segment of length `n`, a lag-2 event has source position `i` and target `j=i+2`.

Primary boundary-eligible event:

`i < 2 OR j >= n - 2`.

This is exactly the boundary definition used in the parent return discriminator. No event width or edge definition may be changed after target output is visible.

## 5. Fixed-marginal nulls

For each context stratum, construct rows `(source_token, target_token)`.

The null keeps every source token fixed and permutes only the target tokens **within the same stratum**. Therefore the source-token marginal and target-token marginal are preserved exactly.

Primary statistic in each panel:

`T = number of rows with source_token == target_token`.

For every stratum with size `N`, source counts `r_a`, and target counts `c_a`, the exact conditional expectation is:

`E[T_stratum] = sum_a r_a*c_a/N`.

The exact conditional variance is computed from the fixed-multiset permutation indicators, including within-token and between-token covariance terms. Stratum expectations/variances are summed because target permutations are independent across strata.

Report:

- observed diagonal count;
- conditional expected count;
- excess count;
- observed/expected diagonal ratio;
- analytic z score;
- one-sided Monte Carlo fixed-marginal permutation p-value using 20,000 deterministic permutations for the primary panel;
- per-event residual `I[source==target] - c_source/N_stratum` aggregated by folio.

## 6. Context panels

### D0 — coarse diagnostic

`section × source_edge_coordinate × target_edge_coordinate`

Diagnostic only.

### D1 — length-bucket diagnostic

`section × inherited length_bucket × source_edge_coordinate × target_edge_coordinate`

Diagnostic only.

### D2 — primary strict fixed-marginal panel

`section × exact segment length n × source_edge_coordinate × target_edge_coordinate`

where edge coordinate is inherited `L0-L3`, `R0-R3`, or `M`.

D2 is the primary test because exact segment length was the strongest deterministic line-shape refinement already tried in the parent programme.

### D3 — cross-fitted latent-template robustness panel

Use the parent K=8 delexicalised boundary-template definition:

- length bucket of each boundary token (`1-2`,`3-4`,`5-6`,`7+` STA-family units);
- first STA-family sign;
- last STA-family sign;
- missing-coordinate markers;
- no equality, lag, ED1, or complete-token-identity feature.

For each of the inherited five folio folds:

1. learn K=8 prototypes on the other four folds only;
2. assign each held-out line to its nearest prototype using deterministic Hamming distance and lowest-index tie-breaking;
3. pool held-out events across folds and stratify as:

`section × length_bucket × source_edge_coordinate × target_edge_coordinate × cross_fitted_Z`.

No held-out equality statistic may affect prototype learning or assignment.

D3 is a conservative robustness panel against a latent line-template mixture explanation. K=4 and K=12 are sensitivity diagnostics only.

## 7. Primary identity-coupling gate

D2 receives `DIAGONAL_PASS` only if all hold:

1. observed/expected diagonal ratio >= 1.10;
2. analytic one-sided z >= 2.58;
3. 20,000-permutation one-sided p <= 0.01;
4. folio-block bootstrap (5,000 resamples) 95% CI lower bound for mean per-event residual > 0;
5. at least 4/5 inherited folio folds have positive total residual.

D3 receives the same ratio/z/bootstrap/fold-direction thresholds; its primary permutation p-value is also <=0.01, using 20,000 deterministic within-stratum target permutations.

## 8. Calibration controls

### C0 — exact marginal preservation audit

For every randomized replicate, verify that every stratum's source Counter and target Counter are bit-for-bit identical to the observed stratum marginals. Any failure => `INSTRUMENT_FAIL`.

### C1 — N1-destroyed-order controls

Create 200 deterministic N1-shuffled versions of the real corpus using the inherited N1 groups. Run D2 on each shuffled corpus. D2 detector calibration passes only if:

- <=5% of controls meet the analytic D2 gate (ratio >=1.10 and z>=2.58);
- median control z is between -0.5 and +0.5;
- the real D2 z exceeds the 99th percentile of the 200 control z values for a positive target claim.

### C2 — template-only negative controls

Generate 50 complete OOF B2 template-only synthetic corpora from the frozen parent B2 architecture, with no return operation. Run D2 and D3. For each panel, <=5% may meet its analytic gate. Otherwise `INSTRUMENT_FAIL`.

### C3 — planted identity-positive controls

Generate 30 matched B2 synthetic corpora, then at boundary-eligible lag-2 targets plant exact identity with probability q=0.03. Run D2 and D3. At least 80% must meet the analytic gate in each panel. Otherwise `INSTRUMENT_FAIL`.

q=0.03 is fixed before target inspection and is a detector-sensitivity calibration, not an estimate of the Voynich effect.

## 9. Hostile specificity diagnostics

Using the same fixed-marginal construction, report exact-identity diagonal tests at lags 1, 3, and 4 with contexts:

`section × exact segment length × source_edge_coordinate × target_edge_coordinate`.

These are not fitted and do not rescue or veto the D2/D3 primary conclusion. They determine whether any surviving identity effect is uniquely lag-2 or part of broader identity coupling.

Also report left-boundary and right-boundary D2 residuals separately. These are descriptive only and may not be used to redefine the boundary.

## 10. Adjudication hierarchy

1. Any source/alignment/calibration failure => **INSTRUMENT_FAIL**.
2. D2 fails `DIAGONAL_PASS` => **FIXED_MARGINALS_EXPLAIN_LAG2_DIAGONAL**. No identity-specific coupling supported.
3. D2 passes but D3 fails => **LATENT_TEMPLATE_MIXTURE_NOT_EXCLUDED**. Coarse positional marginals are insufficient, but identity coupling is not established after latent-template control.
4. D2 and D3 both pass => **IDENTITY_DIAGONAL_ENRICHED**.

The final label `IDENTITY_DIAGONAL_ENRICHED` means only that exact token identity is overrepresented after the preregistered fixed-marginal controls. It does not imply a production direction or copying mechanism.

## 11. Prohibited rescue moves

After target output is visible, v0.1 may not change:

- event/boundary width;
- exact-length versus bucket primary status;
- edge-coordinate definition;
- K=8 primary latent template;
- fold assignment;
- ratio/z/p/bootstrap thresholds;
- q=0.03 positive-control strength;
- token representation;
- lag target;
- strata backoff rules.

No stratum backoff is permitted in D2/D3. Strata of size 1 contribute their fixed observed expectation and zero randomization variance; they provide no evidence for or against coupling.

Any revised detector requires a separately frozen v0.2.

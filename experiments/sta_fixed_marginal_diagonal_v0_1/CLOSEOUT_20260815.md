# STA fixed-marginal boundary diagonal v0.1 — closeout

Date: 2026-08-15
Formal preregistered verdict: **INSTRUMENT_FAIL**.

## What the real corpus does

The fixed-marginal diagonal itself is very strong. On 14,169 boundary-eligible STA-family lag-2 events:

- observed exact matches: 225;
- D2 exact-length fixed-marginal expectation: 125.54;
- excess: +99.46;
- observed/expected: 1.792;
- analytic z: 9.21;
- 20,000-permutation one-sided p < 5e-5;
- folio bootstrap residual CI is wholly positive;
- all five folds have positive residual.

The cross-fitted K=8 latent-template panel D3 is at least as strong:

- expectation 121.78;
- ratio 1.848;
- z 9.77;
- permutation p < 5e-5;
- all five folds positive.

Thus ordinary section/position/length endpoint marginals, and the tested K=8 delexicalised template state, do not by themselves reproduce the observed diagonal.

## Why this is not evidence for a lag-2 return mechanism

The calibration veto fires decisively.

### N1 destroyed-order controls

Across 200 deterministic N1-shuffled corpora:

- median D2 z = 7.748;
- median D2 diagonal ratio = 1.672;
- 100% satisfy the nominal analytic diagonal gate;
- 99th-percentile z = 9.890;
- the real D2 z = 9.210 does **not** exceed that p99 control threshold.

N1 shuffling destroys the relevant within-zone ordering while preserving line membership and boundary-zone token inventories. Therefore a large fixed-context diagonal can arise without the original sequential pairing.

### Template-only controls

The frozen B2 template-only generator also yields nominal diagonal positives too often:

- D2: 14% false-positive gate rate;
- D3: 10% false-positive gate rate.

The q=.03 planted positive controls are detected in 100% of D2 and D3 replicates, so the detector has ample sensitivity; its problem is specificity.

## Hostile lag diagnostics

The identity excess is not confined to lag 2 under the same exact-length fixed-marginal construction:

- lag 1: ratio 1.529, z 6.57;
- lag 3: ratio 1.666, z 7.20;
- lag 4: ratio 1.630, z 6.33.

Both line sides also carry the effect:

- left boundary: ratio 1.966, z 8.23;

K sensitivity does not remove it: K=4 gives ratio 1.812 / z 9.40; K=12 gives ratio 1.688 / z 8.60.

## Revised scientific conclusion

The previous statement that a special `A ? A` lag-2 return residue might require identity memory is no longer justified.

The evidence now points to a broader phenomenon:

> **Nearby positions within the same line/boundary regime draw from strongly shared line-local or zone-local token inventories. That heterogeneity produces excess exact identity across several short lags, even after global positional marginals are fixed and even when the original ordering is destroyed.**

This explains why the previous B3 predictive test falsely appeared to support exact return memory and why the current fixed-marginal diagonal remains significant under N1 controls.

The representation-robust fact that exact lag-2 recurrence is boundary-associated still stands descriptively, but it is not currently isolated as a lag-2-specific mechanism.

## Next justified discriminator

Do **not** add another copy/return parameter.

The next test should condition on the local inventory that N1 preserves. A clean v0.2 target is a **within-line / within-boundary-zone conditional diagonal test**:

1. preserve each line's first-two, middle, and last-two token multisets exactly;
2. randomize token order only within those line-specific zones;
3. score lag 1/2/3/4 exact identity simultaneously;
4. compare the real lag-2 residual directly with this line-local null;
5. require lag-2 to exceed the other short lags if any lag-2-specific mechanism is to be claimed.

If real lag-2 collapses under that null, the mechanism-level conclusion is local inventory/line-template clustering rather than identity return. If a lag-2-specific residual survives, only then is a new sequential-coupling model justified.

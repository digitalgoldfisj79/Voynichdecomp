# SVT v0.3.4 — Primitive-period canonicalisation gate

Status: FROZEN BEFORE BINDING EXECUTION
Date: 2026-08-21

## Motivation
SVT v0.3.3 failed its exact state-structure gate 7/8 despite 99.33% mean plaintext recovery. The sole failure was a periodic true-period-2 trial for which the cheap screen ranked the primitive period 10th and the final selected model was periodic period 4 with 98.05% plaintext recovery. Periods 6, 8 and 10 also recovered the plaintext strongly. This is consistent with harmonic superperiod aliasing: a period-4 state schedule can represent an ABAB process generated by primitive period 2.

v0.3.3 remains formally FAILED. v0.3.4 is a new test and does not alter or reinterpret that gate.

## Canonicalisation rule
No map-distance threshold is introduced.

After a blind model selects `(mode, period=p)`, enumerate `p` and every proper divisor `d >= 2` of `p`. For each candidate divisor, refit the unchanged v0.3.1 state/key solver with exactly 12 independent starts. Select by the same frozen penalised model score:

`raw language score - local-move BIC - schedule BIC`.

The canonical period is the divisor with maximum penalised score. Plaintext truth is not consulted. Mode is not changed by canonicalisation.

Rationale: if a superperiod merely duplicates a smaller primitive cycle, the smaller model should obtain comparable likelihood with lower schedule complexity. If it cannot, the primitive period is not autonomously identifiable under this model.

## Binding Arm A — fresh blind ordinary trials
- Language: German (`de`).
- Length: 1536 plaintext characters.
- Split: `dev`.
- Fresh replicate namespace: offset 13000.
- Eight trials: true mode in `{periodic, line_reset}` x replicate `0..3`.
- None of these replicates was used by v0.3, v0.3.1, v0.3.2, v0.3.3, or the v0.3.3 schedule-screen calibration.

For each trial:
1. screen all 22 candidate structures (2 modes x periods 2..12) with the unchanged truth-free v0.3.3 screen;
2. retain exactly top 6;
3. run exactly 12 v0.3.1 key starts for each retained structure;
4. select by frozen penalised score;
5. canonicalise the selected period over its divisors using the rule above;
6. reveal truth only after the final canonical selection.

Binding Arm-A gate, all required:
- canonical mode+primitive-period exact recovery = 8/8;
- mean plaintext recovery >= 0.95;
- median plaintext recovery >= 0.97;
- minimum plaintext recovery >= 0.85;
- all 8 recoveries >= 0.90.

The screen truth rank is recorded but is NOT itself a v0.3.4 gate: harmonic canonicalisation is specifically intended to permit an exact primitive period to be absent from the top 6 when a superperiod alias survives and is later reduced autonomously.

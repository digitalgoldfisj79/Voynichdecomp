STAGE 1 - JOIN OBJECTS TO FRAGMENTS (SQL and geometry only)
For each non-container object, find the fragment whose label box is
nearest within the same row of the concordance; labels normally sit to
the right of their fragment. Record distance and a confidence flag.
List objects with no label within reach, labels with no object, and
fragments claimed by several objects (root + leaf of one plant is
expected). Part shown per fragment = the obj_class values linked to it.
Check by eye on a sample only: the first row of every page plus every
flagged case. Report the sample's error rate. Write the result to a new
table and a CSV, and hash it.

STAGE 2 - SAME-PLANT PAIRS, BLIND TO LABELS
Write the grading rules into the results file before viewing anything:
A = same drawing in all visible parts; B = same in one part, others
absent or unclear; C = generic resemblance only.
Shortlist candidate pairs cheaply from what exists (same obj_class,
similar box shape and colour, any existing shape or embedding scores),
then view only the shortlisted crops and grade them. Do not read
label_zl until the graded list is saved and hashed.

STAGE 3 - TESTS (pre-register each before running: what confirms, what
falsifies, the null, and the power)
T4 (names written differently each time): for grade-A and grade-B
  pairs, is the edit similarity between the two labels higher than for
  random fragment pairs matched on page distance?
T3 (labels mark parts or properties): do label features (first glyph,
  last glyph, length) differ by part shown, with page held fixed
  (permute part within page)?
T2b (labels point into nearby text): does a row's label occur in the
  paragraph block directly after that row more than in other blocks of
  the same page and of other pages? The earlier attempt compared block
  hits with a page-level null and is void; build the null at block
  level.

## Fidelity gate F0

Run the pinned jar with the pinned default configuration and seed 19. Compare the produced `generated_text.txt` byte-for-byte/SHA-256 with the pinned repository copy `executable/generate/generated_text.txt`.

- PASS: exact byte identity.
- If FAIL: stop primary inference until the discrepancy is classified as environment/Java-output formatting or a genuine executable/config mismatch. No generator parameter may be changed to force agreement.

## Voynich target corpus

Primary target: ZLZI standard paragraph loci only (`P0`), exactly as defined in the preceding LAAFU v0.3 programme. No circular/radial/label loci.

Primary observable `N1_ED1`: adjacent tokens are non-identical and ordinary unit-cost character Levenshtein distance exactly 1.

Secondary observable `E1`: exact adjacent equality.

Null for both: independent **within-line exact-token-multiset-preserving permutation**. Thus the metric tests word order conditional on the words already assigned to each line.

The P0 N1_ED1 target has not been computed before this preregistration. Its ratio will be measured after freeze using 2,000 permutations. A generator is considered quantitatively matched on N1_ED1 if its ratio lies within ±0.05 absolute ratio units of the observed P0 target. This equivalence margin is frozen now.

For E1, the inherited VMS result is approximately chance; the generator compatibility band is frozen as ratio in [0.90,1.10] OR |z|<2.

## Primary generator tests

### G0 — published default, seed 19

Run the exact published default configuration. Analyse its native generated lines with 2,000 tight-null permutations.

`H-TIMM-DEFAULT`: SUPPORT iff:
1. F0 passes;
2. generated N1_ED1 ratio is within ±0.05 of the P0 VMS target;
3. generated N1_ED1 z>=3;
4. generated E1 is compatible with the VMS chance band above.

If N1 matches but E1 does not, verdict = PARTIAL: the published mechanism is sufficient for the near-neighbour effect but not the joint adjacent-order signature.

### G1 — seed replication

Run the unmodified published configuration at pseudo-random seeds 1..20 inclusive (seed 19 therefore appears in the panel but is not counted twice). 500 tight-null permutations per run.

`H-TIMM-ROBUST`: SUPPORT iff:
- median N1_ED1 ratio is within ±0.05 of P0 VMS;
- >=15/20 runs have N1_ED1 ratio>1 and z>=2;
- >=14/20 are within ±0.08 of the P0 VMS ratio;
- median E1 ratio is in [0.90,1.10].

This tests mechanism-family sufficiency rather than one lucky pseudo-random run.

## Pre-specified ablations

Ablations use seeds 1..10, 500 null permutations each. They are mechanistic diagnostics, not alternative fitted models.

### A1 — random source chooser

Change only `method.sourceChooser=page` -> `random`.

Prediction if local/page donor selection is necessary for the tight-null adjacency effect: median N1_ED1 enrichment should fall by >=0.05 absolute ratio units relative to the paired default seeds, and paired differences should be positive in >=8/10 seeds.

### A2 — no immediate reuse of newly generated token

Change only `method.morph.reuse_last.probability=10` -> `0`.

Prediction if the explicit reuse-last channel materially drives adjacent near-neighbours: same criterion, median drop >=0.05 and positive paired default-minus-ablation difference in >=8/10 seeds.

### A3 — position source chooser (shipped alternative)

Change only `method.sourceChooser=page` -> `position`.

This is descriptive. No success criterion. It tests whether the more explicitly position-local shipped chooser strengthens or weakens N1_ED1 under the same tight null.

## Controls and parsing

- Generated text is parsed as one whitespace-tokenized line per output line; blank/comment/config lines, if any, are identified from the actual file format and excluded by a deterministic parser frozen in code before scoring.
- No pair crosses a generated line.
- The existing validated exact-distance-one implementation from joint-lag v0.1 is reused.
- C0: for the seed-19 generated corpus, create 20 pseudo-corpora by within-line shuffling and score each against 200 fresh shuffles. N1_ED1 mean ratio must lie [0.95,1.05] and <=2/20 have |z|>=2.
- C1: inject ED1 adjacency into 2% of non-overlapping eligible adjacent positions in a shuffled pseudo-corpus; N1_ED1 must reach ratio>=1.15,z>=3.

If either control fails, N1 mechanistic inference stops.

## Interpretation discipline

A successful result establishes **statistical sufficiency** of the published Timm–Schinner generator for the conditioned near-neighbour property. It does not establish that a Voynich scribe historically copied/mutated a source word, nor that the manuscript is meaningless. A failure means the qualitative Timm phenomenon is real but this published implementation does not reproduce its tight-null form under the frozen defaults.

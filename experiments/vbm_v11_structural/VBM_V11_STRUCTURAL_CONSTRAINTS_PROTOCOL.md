# VBM v11 — Structural Constraint Programme

Date: 2026-09-02
Status: **PREREGISTERED BEFORE V11 OUTPUT**
Parent: V10 closeout `VBM_GLOBAL_KEY_NOT_RECOVERABLE_EVEN_COMPACT`.

## Purpose

V10 showed that whole-nucleus global dictionary recovery is non-identifying under language-model optimisation: wrong keys can score like or better than the true key. V11 therefore does **not** search plaintext and does **not** optimise German, Italian, Latin, or any other language against Voynich.

V11 asks whether the ciphertext itself supports additional structure that could make a future VBM-style cipher identifiable.

Five independent branches are tested:

A. contextual homophone classes among vowel bridges;
B. compositional nucleus morphology, especially `e`-family ladders;
C. factorisation of bridge behaviour into its two visible halves;
D. simple morphology -> consonant-run-length rules;
E. line-edge bridge closure.

A positive branch is evidence only for the stated structural regularity. It does not validate VBM or identify plaintext.

## Common corpus and parser

Use the unchanged Joachim-exact v9 Q0b parser:

- ZLZI transcription from `voynich_transcriptions_slim.json`;
- atoms `ckh, cth, cph, cfh, ch, sh, qo` recognised as left token halves;
- other token left halves are the first glyph;
- token right half is the final glyph;
- token interior is the nucleus;
- single-glyph tokens are shared left/right halves with empty nucleus;
- invalid tokens terminate a segment;
- bridge between adjacent tokens is `right(previous)|left(next)`;
- previously reserved H1 and C1 folios remain excluded.

No parser change is allowed after results are exposed.

For actual-Voynich structural inference, all remaining folios are divided deterministically by SHA256 into TRAIN (80%) and INTERNAL_HOLDOUT (20%) exactly as Q0b. Where split-half stability is required, TRAIN folios are further divided by SHA256 parity into TRAIN-A and TRAIN-B.

The inferential unit for null resampling is the folio or segment as stated below, never the individual bridge occurrence.

## Synthetic calibration

Where a method claims to recover hidden VBM classes, it must first pass known-answer synthetic calibration generated by the frozen V10 compact global-codebook generator:

- 30 bridge surface types mapped to five true vowel classes;
- 96 nucleus surface types mapped to 32 true consonant-run classes;
- 2,000 lines per replicate;
- 3 German-generator and 3 Italian-generator replicates;
- inference receives factor streams only, not language labels, plaintext, or keys.

Modern language material is used only to generate known-answer synthetic factor streams. No language likelihood enters the Voynich tests in branches A, B, C, or E.

## Branch A — Contextual homophone recovery

### Hypothesis

If many visually different bridge types are homophones for only five vowels, bridge types belonging to the same latent vowel should be approximately substitutable and therefore have similar distributions over neighbouring nucleus contexts.

### Features

For each bridge occurrence record:

- left non-empty nucleus type or `EMPTY`;
- right non-empty nucleus type or `EMPTY`;
- bridge position bucket within segment: FIRST / MIDDLE / LAST / SINGLE.

Context vectors use the 64 most frequent TRAIN nucleus types plus `OTHER` and `EMPTY`, separately for left and right neighbours, plus position buckets. Counts receive additive smoothing 0.5 and are normalised.

Only bridge types with >=20 TRAIN occurrences are eligible for primary clustering.

### Distance and clustering

- Jensen-Shannon distance between context vectors;
- agglomerative average-linkage clustering;
- evaluate k=2..10;
- primary k=5.

### Synthetic method qualification

For each of six synthetic replicates, cluster eligible bridge types at k=5 and compare with true vowel classes using adjusted Rand index (ARI).

Method qualifies only if:

- median ARI >= 0.70; and
- at least 4/6 replicates have ARI >= 0.50.

If calibration fails, Voynich k=5 clustering is descriptive only and cannot support VBM.

### Voynich primary statistics

1. k=5 silhouette score on TRAIN;
2. TRAIN-A vs TRAIN-B k=5 partition stability, ARI on bridge types eligible in both halves;
3. k-specific silhouette curve k=2..10.

### Null

100 deterministic folio-stratified context-permutation nulls: within each folio and position bucket, permute the neighbouring context records among bridge occurrences while keeping observed bridge labels fixed. This preserves bridge frequency, folio composition, and position composition while destroying bridge-specific contextual selectivity.

### Gate A

`A_SUPPORT_FIVE_CONTEXT_CLASSES` only if synthetic qualification passes and:

- observed k=5 silhouette > 99th percentile of null silhouettes;
- observed split-half ARI > 99th percentile of null split-half ARIs; and
- k=5 silhouette is within 0.05 of the best observed silhouette across k=2..10.

Otherwise: `A_NO_FIVE_CLASS_EVIDENCE`.

## Branch B — Compositional nucleus morphology / e-family ladders

### Primary hypothesis

Nuclei differing only in the number of consecutive `e` glyphs should have more similar bridge-context distributions than frequency- and length-matched unrelated nucleus pairs if `e` count is a compositional modifier rather than part of an arbitrary whole-nucleus lookup key.

### Eligible nuclei

Non-empty nucleus types with >=20 TRAIN occurrences.

Define `e`-skeleton by replacing every maximal `e+` run with a single `E`. An `e`-ladder pair consists of two eligible nuclei with the same skeleton but different total `e` count.

### Context vector

For each nucleus type, distribution of immediately preceding and following bridge types, with the 64 most frequent bridge types plus `OTHER`; additive smoothing 0.5.

### Statistic

Median Jensen-Shannon distance over all eligible e-ladder pairs.

### Matched null

10,000 deterministic matched samples. For each ladder pair, replace one member by an unrelated eligible nucleus matched on:

- occurrence-frequency decile;
- raw nucleus length +/-1;
- same initial glyph class where possible.

Primary effect is z-score of observed median distance relative to matched-null medians; empirical one-sided p-value also reported.

Repeat independently on TRAIN-A and TRAIN-B.

### Gate B

`B_E_LADDER_COMPOSITIONALITY_SUPPORTED` only if:

- at least 20 eligible e-ladder pairs exist in full TRAIN;
- full-TRAIN z >= 2.5 and empirical p <= 0.01;
- both TRAIN-A and TRAIN-B effects point in the same direction and each z >= 1.5.

Other morphology families may be reported exploratory but cannot rescue the primary gate.

## Branch C — Bridge factorisation into visible halves

### Hypothesis

The behaviour of bridge `R|L` is generated substantially by the visible right-half `R` and left-half `L`, rather than each full pair being an arbitrary independent symbol.

### Prediction target

Predict neighbouring nucleus context separately for the left and right side. Context outcome is the 32 most frequent non-empty nucleus types plus `OTHER` and `EMPTY`.

### Models

Using TRAIN counts and INTERNAL_HOLDOUT evaluation:

- `M0`: pooled context distribution;
- `MPAIR`: smoothed distribution conditional on full bridge type;
- `MADD`: multiplicative/additive-half model
  `P(c|R,L) proportional P(c|R) * P(c|L) / P(c)`, with identical Dirichlet smoothing.

Evaluate held-out mean log probability for left and right contexts.

Define pair gain = `LL(MPAIR)-LL(M0)` and additive gain = `LL(MADD)-LL(M0)`.

Factorisation ratio = additive_gain / pair_gain where pair_gain>0.

### Null

100 deterministic mappings that permute L-half identities among bridge types within bridge-frequency deciles, preserving R halves and full bridge occurrence counts but destroying the actual R/L composition.

### Gate C

`C_BRIDGE_HALVES_FACTORISE` only if for both left- and right-context predictions:

- pair gain > 0;
- factorisation ratio >= 0.80; and
- actual additive gain > 99th percentile of half-permutation null gains.

Otherwise `C_NO_STRONG_HALF_FACTORISATION`.

## Branch D — Morphology -> consonant-run length

### Hypothesis

A very small, fixed morphology rule maps each non-empty nucleus to a consonant-run length 1..5, reducing the arbitrary whole-nucleus codebook.

### Frozen candidate rule family

For nucleus string `n`, define `ecount` = total number of `e`, `emax` = longest consecutive e-run, `len` = glyph length.

Rules:

- D1: `1 + min(4, ecount)`;
- D2: `1 + min(4, emax)`;
- D3: `min(5, len)`;
- D4: `min(5, 1 + ecount + I(last in {d,y,r,l}))`;
- D5: `min(5, max(1, len - ecount + 1))`.

Empty nuclei have run length 0. Every visible bridge contributes one vowel separator.

### Reference structural models

Build consonant-run-length Markov models from independent deterministic German and Italian `wordfreq` banks, using only sequences of consonant-run lengths between vowels. No character identities are used.

For each rule, score Voynich TRAIN and INTERNAL_HOLDOUT run-length sequences under both reference models.

### Null and multiplicity control

For each rule, 1,000 deterministic nulls shuffle the rule-assigned lengths among nucleus **types** within occurrence-frequency deciles, preserving the rule's global length distribution and approximate frequency relationship. For each null take the maximum improvement over D1..D5; compare the observed maximum rule improvement against this familywise-max null.

### Gate D

`D_SIMPLE_LENGTH_RULE_SURVIVES` only if one predeclared rule:

- exceeds the 99th percentile familywise-max null on INTERNAL_HOLDOUT for both German and Italian run-length models;
- has the same winning rule on TRAIN and INTERNAL_HOLDOUT.

Otherwise `D_NO_SIMPLE_MORPHOLOGY_LENGTH_RULE`.

This is structural compatibility only, not language identification.

## Branch E — Line-edge closure

### Hypotheses

E1 sequential closure: final right half of a segment/line pairs with the initial left half of the immediately following valid segment/line in the same folio.

E2 cyclic closure: final right half pairs with the initial left half of the same segment.

### Statistics

Using the empirical TRAIN internal bridge distribution:

- support rate: fraction of candidate edge pairs attested at least once as an internal bridge in TRAIN;
- mean smoothed internal-bridge log probability.

### Nulls

10,000 deterministic within-folio permutations of initial halves among eligible lines/segments, preserving start-half and end-half marginals and folio composition.

E1 is primary. E2 is separately reported and cannot rescue E1.

### Gate E

`E_SEQUENTIAL_CLOSURE_SUPPORTED` only if E1 exceeds the 99th percentile of its null distribution on both support rate and mean log probability in TRAIN, and the direction replicates in INTERNAL_HOLDOUT using the TRAIN internal-bridge model.

Otherwise `E_NO_SEQUENTIAL_CLOSURE_EVIDENCE`.

## Programme decision

No branch can validate plaintext or VBM by itself.

- 0 positive primary branches: `V11_NO_NEW_IDENTIFYING_STRUCTURE`.
- 1 positive branch: `V11_ONE_STRUCTURAL_CONSTRAINT_REQUIRES_INDEPENDENT_MODEL`.
- >=2 positive branches: `V11_MULTIPLE_STRUCTURAL_CONSTRAINTS_JUSTIFY_V12_SYNTHETIC_MODEL`.

A V12 decipherment programme is **not** automatically opened. If >=2 branches pass, the next permissible step is to formulate one explicit, more restrictive generative cipher that incorporates only the independently supported constraints, then validate it synthetically before any Voynich plaintext search.

## Stopping and evidence rules

- No post-result parser changes.
- No language-model plaintext search.
- No branch may be rescued by an exploratory variant.
- Negative branches are committed exactly as positive branches are.
- H1/C1 plaintext firewall remains sealed.
- CPU execution is preferred; no paid GPU run is authorised by this protocol.

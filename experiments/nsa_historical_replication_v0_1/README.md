# NSA Historical Replication Programme v0.1

Preregistered reconstruction of three underexploited NSA-era Voynich analyses:

1. D’Imperio’s 1978 40-page monographic clustering panel.
2. Currier’s line-boundary and cross-token terminal→initial dependencies.
3. D’Imperio’s PTAH-style latent positional structure at glyph, token, and sub-token scales.

The programme is intentionally isolated from manuscript drafting. Results are promoted only after integrity checks, negative controls, sensitivity analysis, and exact provenance reporting.

Run:

```bash
python experiments/nsa_historical_replication_v0_1/run.py --mode full
```

Outputs are written to `experiments/nsa_historical_replication_v0_1/results/`.

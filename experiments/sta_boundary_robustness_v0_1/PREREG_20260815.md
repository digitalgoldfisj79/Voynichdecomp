# STA boundary/local-dependence robustness v0.1 — preregistered 2026-08-15

Frozen before inspecting any target STA score in this branch.

## Scientific question

The preceding ZLZI/P70 programme established three facts in sequence:

1. raw exact lag-2 and adjacent ED1 excesses are real against naive within-line order nulls;
2. both are strongly boundary/position coupled and collapse in the trimmed interior under the frozen LAAFU N1/N3 controls;
3. a held-out zero-lookback model using section, line length, coarse boundary class and P70 empty/nonempty state improves fit but fails to reproduce the raw structural excesses.

This experiment asks whether the substantive residual survives a materially different transcription representation: **RF1b STA-family**.

This is a representation robustness test, not an independent manuscript sample. RF/STA/aaa are correlated views of one transcription.

## Frozen source

Primary source: René Zandbergen RF1b in STA1/IVTFF 2.0, canonical public source:

`https://voynich.nu/data/sta/RF1b.txt`

Expected repository-programme provenance: RF1b SHA-256 `81c331b7d8e76761e27d350c3b37ccfbe192848e6c8a227bcb5d40fb29259b17` was recorded for the earlier audited RF source; this experiment records the downloaded STA file hash separately and does not assume byte identity with a native/RF-member file.

STA-family representation: every full STA member `[A-Z][0-9a-z]` is collapsed to its leading capital family, exactly following the existing programme convention that STA families are identified by the single capital letter.

### Certain-token eligibility

- only loci whose IVTFF locus subtype is `P0` are primary;
- `<->` drawing interruptions are hard segment breaks;
- certain word boundaries are dots;
- a word is eligible only if it is exactly a concatenation of full STA members `(?:[A-Z][0-9a-z])+`;
- comma/uncertain-space, bracketed alternatives, illegibles and other marked words are excluded and create hard breaks so no adjacency is bridged across uncertainty;
- a resulting segment must contain >=2 eligible tokens for ED1 and >=3 for E2.

Section labels are imported only at **folio level** from the frozen `enriched_records.json` occurrence ledger on the parent branch, using the modal section per folio. They do not depend on STA token identity.

## Frozen local statistics

Let ED1 mean Levenshtein distance exactly one over **STA-family units**, excluding identity. Token length means number of STA-family units.

Use the historical LAAFU null geometry unchanged:

- N0: unrestricted permutation within each eligible segment;
- N1: positions 0–1, middle, and last two shuffled separately, using the historical short-line rule for n<5;
- N3: N1 but score only E2 starts `i=2..n-5` for n>=7 and ED1 starts `i=2..n-4` so both endpoints are in the trimmed interior.

Primary descriptive null uncertainty uses 1000 deterministic permutations, seed 20260815.

### R1 — exact lag-2 attenuation

Representation-robust if:

- N0 ratio >=1.10 and z>=2;
- both N1 and N3 are closer to 1.0 in absolute log-ratio than N0;
- and at least one of N1/N3 has ratio <1.10 or |z|<2.

This tests the same substantive geometry rather than numerical equality to ZLZI.

### R2 — adjacent ED1 attenuation

Representation-robust if:

- N0 ratio >=1.10 and z>=2;
- N3 is closer to 1.0 than N0;
- N3 ratio <1.10 or |z|<2.

### R3 — length/crowding discriminator

Partition adjacent ED1 events by mean STA-family token length:

- short <=4 units;
- mid 5–6;
- long >=7.

The long class is a representation-robust anti-crowding residual only if it has >=60 observed events, ratio >=1.15 and z>=2. If observed long events <60, R3 is `UNDERPOWERED`, not failure.

### R4 — production-order direction

Recompute accretion/reduction and first-half/second-half substitution-site ratios against full N0 permutation distributions. Direction remains absent if both |z|<2.

## Held-out zero-memory models

Five deterministic folio folds; 30 complete out-of-fold synthetic corpus replicates per model. Every held-out segment preserves only its section and observed token count. No held-out token identity, state, previous token or neighbour is exposed to training/generation.

All draws are frequency weighted from training folios only with frozen hierarchical backoff. Minimum specific-cell support is 30 occurrences and 5 token types.

### S0

Independent emission conditioned on `(section, segment-length bucket)`.

Segment-length buckets: 2–5, 6–9, 10–14, 15+ tokens.

### S1

S0 + historical coarse N1 position class: first two / middle / last two.

### S2 — stronger representation-native positional model

S0 + exact edge-coordinate class:

- `L0,L1,L2,L3` for positions 0–3 from the left;
- `R0,R1,R2,R3` for positions 0–3 from the right;
- `M` otherwise;
- when a short line position qualifies for both edges, choose the nearer edge; ties choose left.

S2 deliberately gives the memoryless hypothesis **more** positional information than the preceding M2. It contains no P70 variable and therefore cannot inherit the ZLZI/P70 factorisation.

## Model fingerprints

For each synthetic corpus compute the same exact-null ratios as the real STA corpus.

### F1 — E2 boundary geometry

Pass if the median synthetic corpus:

- matches real N0 E2 ratio within absolute 0.05;
- matches real N1 and N3 ratios within 0.05;
- preserves the real ordering of absolute attenuation distances from 1 where the real R1 gate passes.

### F2 — ED1 boundary geometry

Pass if median synthetic N0 and N3 ED1 ratios are each within 0.05 of real.

### F3 — long-word ED1

If R3 is powered, pass if median synthetic long-class ratio is within 0.07 of real and remains >=1.15. If R3 is underpowered, F3 is not scored.

### F4 — no direction

Pass if median synthetic accretion/reduction and substitution-site absolute log deviations from their own null ratios are <=0.20 and the real R4 gate passes.

## Decision rule

- **STA_RESIDUAL_SURVIVES** if real R1 and R2 pass, R4 passes, and S2 fails at least one of F1/F2 (plus F3 if powered). This means a stronger independent exact-position model still cannot generate the local dependence in STA-family representation.
- **STA_POSITIONAL_MODEL_SUFFICIENT** if R1/R2 are present in real STA and S2 passes all scored F1–F4 fingerprints.
- **REPRESENTATION_SENSITIVE** if either R1 or R2 fails in the real STA corpus.
- **INCONCLUSIVE** for source/validation/power failure that prevents the above decisions.

## Guardrails

1. Do not use P70 core-state in the primary STA test.
2. Do not tune thresholds or position classes after seeing target scores.
3. Do not interpret STA family units as linguistic characters; STA is a synthetic handwriting-oriented superset.
4. Do not call correlated RF/STA/aaa views independent replications.
5. If STA residual survives, B1/B2 boundary-template work becomes justified; if representation-sensitive, stop mechanism escalation and diagnose transliteration dependence first.

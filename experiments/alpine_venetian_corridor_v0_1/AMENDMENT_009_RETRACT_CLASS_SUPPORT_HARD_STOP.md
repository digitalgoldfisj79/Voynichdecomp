# Amendment 009 — Retraction of Amendment 008 hard-stop conclusion

Date: 2026-08-08
Run: `corridor_v01_20260808_run01`
Timing: before any corridor-to-Voynich text-description or geometry/morphology similarity has been computed.

## Retraction

Amendment 008 correctly recorded severe visual-class imbalance, but its conclusion that class support makes the confirmatory text and geometry families mathematically incapable of reaching `p < 0.01` was too strong.

The combinatorial p-value floor calculated there applies to a **separate class-specific geography-label permutation test**. That is not the frozen primary scoring design.

Protocol section 10 instead requires:

1. strict VMS/comparandum class matching;
2. null calibration of object similarities **within class** using non-VMS manuscript pairs and/or permutation nulls;
3. robust aggregation within class;
4. aggregation of calibrated class scores to a manuscript-family score;
5. manuscript-level corridor/control permutation of those family/composite scores.

Accordingly, heterogeneous class availability does not by itself impose the class-specific p-value floors in Amendment 008 on the final manuscript-level test.

## What remains valid from Amendment 008

The support matrix itself is correct and remains a major sensitivity concern:

- architecture_cartography: 7 corridor manuscripts, 2 controls;
- diagram_geometry: 6 corridor, 2 controls;
- plant: 1 corridor, 3 controls;
- all other classes are sparser.

Therefore any text/geometry family score must:

- be calibrated within visual class before cross-class aggregation;
- give no score for missing classes;
- never pool raw cross-class similarities;
- report class-availability by geography;
- include a mandatory sensitivity excluding the Venetian cartographic cluster;
- be treated as nonresolving if within-class null calibration cannot be estimated honestly from the sealed corpus.

## Decision

- DINO/pixel family remains **EXCLUDED** by the confound gate; that result is unchanged.
- Blind text-description and explicit geometry/morphology return to **LIVE, pending valid within-class null calibration**.
- Amendment 008 is retained as an audit record but its hard-stop conclusion is superseded by this amendment.

No target similarity had been computed between Amendments 008 and 009, so this correction is pre-outcome.

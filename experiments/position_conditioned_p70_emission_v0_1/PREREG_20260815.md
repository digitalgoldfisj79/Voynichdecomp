# Position-conditioned P70 emission v0.1 — preregistration

Frozen: 2026-08-15, before any model output is generated or scored on this branch.

## Question

Can the recovered ABC/FW signatures be generated on held-out folios by a **zero-local-memory** production model whose only dependencies are section, line length, line-position class, and P70 structural state?

This directly tests the programme synthesis from `abc_fw_recovery_p70_bridge_v0_1`.

## Non-negotiable exclusions

No model may condition token `i` on any earlier or later token in the same line. In particular there is no:

- `reuse_last` or recent-token cache;
- copy/mutate operator;
- edit-neighbour operator;
- lag-2 / ABA return operator;
- phrase template spanning multiple token positions;
- held-out token or held-out P70-state sequence leakage.

Every token position is emitted independently conditional on the model's permitted exogenous state.

## Corpus and folds

Primary representation: ZLZI occurrence records in `enriched_records.json`. P0 loci for the LAAFU-conditioned targets are identified from `voynich_transcriptions_slim.json` using the historical `u[1:] == 'P0'` rule.

Five folio-held-out folds. Folios are stratified by their dominant frozen section. Within section, folios are sorted by SHA256(`20260815|folio`) and assigned round-robin to folds 0..4. All distributions used to generate a folio are estimated from the other four folds only.

The held-out folio supplies only quantities explicitly permitted by the model: section, observed line length, and the deterministic position class implied by line length and token index. M2 does **not** receive the held-out P70 state sequence.

Thirty complete out-of-fold synthetic corpora are generated per model using fixed seed family 20260815 + replicate/model/fold offsets. Each complete synthetic corpus consists solely of held-out generations, so no scored token was emitted by a model trained on its own folio.

## Frozen line structure

Line-length bins:

- `S`: 1–6 tokens;
- `L7_9`: 7–9;
- `L10_12`: 10–12;
- `L13_16`: 13–16;
- `L17P`: 17+.

LAAFU position class is copied from the August-13 N1 partition:

- for n>=5: first two positions `START`, positions 2..n-3 `MID`, final two `END`;
- for n<5: first min(2,n) `START`, remaining positions `END`.

## Nested models

### M0 — section + line length

For each position, sample a complete training token from the empirical distribution keyed by `(section, line_length_bin)`, with frozen backoff to `section`, then global corpus.

### M1 — add line-position/LAAFU class

Sample a complete training token from `(section, line_length_bin, position_class)`, with deterministic backoff:

1. `(section, position_class)`;
2. `(section, line_length_bin)`;
3. `section`;
4. global.

### M2 — add generated P70 core-state + P70 signature emission

First sample `empty_core` / `nonempty_core` from the training empirical distribution keyed by `(section, line_length_bin, position_class)`, with backoff to `(section, position_class)`, `section`, then global.

Then sample an observed P70 signature tuple `(prefix, gallows, core, suffix)` from training records conditional on `(section, line_length_bin, position_class, sampled_state)`, with backoff:

1. `(section, position_class, state)`;
2. `(section, state)`;
3. `state` globally.

A signature is emitted as its canonical training-token spelling. If a signature maps to more than one spelling in training, the highest-frequency spelling is used with lexical tie-break. This retains the frozen P70 within-token factorisation while introducing **no cross-token dependency**.

M2 is not allowed to privilege the historical top-20 ABA carrier list.

## Exact null scoring

The primary model comparison uses exact permutation-null **means**, not noisy Monte Carlo estimates. For each scored pair of output positions, the expected metric under N0 or N1 is computed by enumerating the ordered item-pair distribution induced by the relevant within-line permutation groups. N3 uses the historical trimmed-interior position ranges under N1.

Before model scoring, the exact-null scorer must validate against the recovered real-data signatures:

- ABC length observed counts exactly `short=598, mid=501, long=146` on the all-line recovered frame;
- P0 ZLZI token count `33200`;
- P0 empty-core E2 N0/N1/N3 ratios within 0.03 absolute of `1.212 / 1.079 / 1.084`;
- P0 same-state ED1 N0/N1/N3 ratios within 0.04 absolute of the state-split recovery.

Failure aborts model interpretation.

## Five frozen fingerprints

All gates below apply to the **median complete OOF synthetic corpus across 30 replicates**. Replicate pass fractions are also reported but do not relax a failed median gate.

### F1 — empty-core lag-2 is raw-excess / conditioned-null

PASS iff:

- P0 empty-core E2 N0 ratio is in `[1.10, 1.32]`;
- N1 ratio `< 1.12`;
- N3 ratio `< 1.12`.

### F2 — ED1 is P70-state-preserving and boundary coupled

PASS iff all:

- P0 both-empty ED1 N0 ratio `>=1.10`;
- P0 both-nonempty ED1 N0 ratio `>=1.15`;
- under N1, at least one same-state class ratio `>=1.07` and mixed-state ratio `<1.10`;
- under N3, both same-state ratios `<1.10`.

### F3 — ED1 is not short-string crowding

On all recovered lines under N0:

- long-word ED1 ratio `>=1.15`;
- short-word ED1 ratio `>=1.10`;
- long ratio > mid ratio.

### F4 — no production-order arrow

For all-line ED1, compare the observed accretion/reduction ratio and first-half/second-half substitution ratio with their exact N0 expectations. PASS iff for each statistic

`abs(log(observed_ratio / null_expected_ratio)) < 0.15`.

Zero-denominator replicates fail that statistic.

### F5 — carrier-like ABA has high middle-slot freedom without a carrier rule

Using the frozen historical top-20 list **only for scoring**, not generation, pool exact `A B A` events whose A is in that list. PASS iff:

- pooled n >= 50;
- `H(B)/log2(n) >= 0.80`.

The model receives no carrier indicator.

## Overall decision

- `QUALIFIED_MEMORYLESS_ARCHITECTURE`: all F1–F5 pass for the median M2 OOF corpus.
- `PARTIAL_MEMORYLESS_ARCHITECTURE`: exactly four pass.
- `FAILED_MEMORYLESS_ARCHITECTURE`: three or fewer pass.

M0 and M1 are diagnostic nested controls; they cannot rescue M2. Their purpose is to identify which added state variable produces any improvement.

For each model also report a target-distance score: root-mean-square difference between generated and real-data log ratios over the numeric ratio components of F1–F4. Lower is better. This is descriptive and does not override the frozen gates.

## Next-mechanism rule

If M2 qualifies, do not add a local kernel for these signatures.

If M2 fails, identify the smallest failed fingerprint. Only that residual may become the target of a subsequent local mechanism. No generator expansion is permitted merely because a generic /84 score would improve.

## Guardrails

This experiment tests production architecture only. P70 labels are operational statistical states, not semantic categories. Same-corpus model design means successful held-out-folio prediction is materially stronger than the preceding descriptive analyses, but cross-transliteration robustness remains required before generalisation beyond ZLZI.

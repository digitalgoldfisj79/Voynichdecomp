## MG3 QUESTION
Can the MG2 free-generation failure be repaired by adding only a held-out-safe, static folio-level lexical palette for the training-seen vocabulary, without adding a new sequential copying rule or changing the novelty generator?

## FROZEN BASE
Data, ZLZI/TTLI dumps, outer folds (folio number mod 5), seven inner splits, AtomModel, novelty gate, MG2 count/ED/opener/boundary/position/recency/section-cache features, L2 penalties, optimiser, diagnostics and 32-replicate generation are unchanged from MG2. MG2 parameters are refit from scratch under the identical code in each job. Existing MG2 weights are NOT retuned to compensate for the new palette.

## NEW MODULE: EMPIRICAL-BAYES STATIC FOLIO PALETTE
At the start of each generated held-out folio, once only:
1. Eligible donor folios are OUTER-TRAINING folios with the same section x Currier label as the target folio. If fewer than 4 exist, fall back to same section. If still fewer than 4, fall back to all outer-training folios.
2. Sample one eligible donor uniformly. The donor remains fixed for the whole generated folio.
3. Let p_g be the global outer-training token distribution over the MG2 training vocabulary.
4. Let m be the median token count of eligible donor folios. Let c_G be the pooled token counts of the eligible donor pool and N_G their token total. Define p_0=(c_G + m p_g)/(N_G+m).
5. For the sampled donor with counts c_D and length N_D, define p_D=(c_D + m p_0)/(N_D+m).
6. Add log(p_D/p_0) to the MG2 score of each ORIGINAL TRAINING-VOCABULARY candidate at every position of that target folio. No adjustment is applied to coined/novel types.

There is no fitted palette strength, no use of held-out target-folio token outcomes, and no new order/lag feature. The module is a non-parametric posterior-predictive draw of a static page-level lexical propensity. Replicate randomness includes donor choice.

## PRIMARY LOCK-1 CRITERIA
32 replicates, same 40 non-degenerate run_joint diagnostics as MG2.

CLOSES on a layer only if ALL hold:
1. observed max |z| <= replicate-vs-replicate 95th percentile of max |z|;
2. every previously designated UNTARGED/indirect statistic has |z| <= 3;
3. zero runaway replicates (one type >6% of a generated fold's tokens);
4. all five exact page_reuse_* diagnostics have |z| <= 3 (anti-cheating gate: repertoire cannot be fixed merely by over-repetition);
5. new folio_seen_Mplus has |z| <= 3;
6. new folio_seen_TTR has |z| <= 3;
7. kept-8 C2ST mean AUC <0.65, provided the real-vs-real gate is itself <0.65.

FALSIFIED if max |z| >10 OR >=3 runaway replicates. Otherwise NOT CLOSED / PARTIAL if any closure gate fails.
Lock 1 is called closed only if BOTH ZLZI and TTLI CLOSE under the identical pipeline.

## NEW FOLIO DIAGNOSTICS
For each real/generated held-out fold, define training-seen using the real other-four-fold vocabulary.
- folio_seen_Mplus: for each training-seen token occurrence, min(4, raw-character ED to any EARLIER NON-IDENTICAL training-seen token on the same folio); if none, 4. Pool occurrences across folds.
- folio_seen_TTR: sum over folios of distinct training-seen types / sum over folios of training-seen token occurrences.
These diagnostics are computed from generated text without using target-folio outcomes during generation.

## INTERPRETATION BOUND
A pass licenses only: a compact MG2 surface generator plus an independently sampled static folio lexical palette reproduces the declared held-out statistics under free generation. It does not identify scribal behaviour, physical devices, copying, semantics or plaintext.

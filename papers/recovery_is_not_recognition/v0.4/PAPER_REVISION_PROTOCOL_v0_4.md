## 2. Governing revision question

## 3. Evidence classes

The revision uses the same separation enforced in the Fortune paper workflow:

- **PUBLISHED:** supported directly by a cited publication or edited source.
- **MACHINE-CERTIFIED:** produced by frozen code and recorded machine-readable artefacts.
- **DERIVED-EXACT:** exhaustive arithmetic or counting from a closed published table.
- **INTERPRETIVE:** synthesis derived from published or machine-certified premises.
- **OPEN:** unresolved or unavailable evidence; excluded from positive manuscript claims.

No claim may be promoted between classes without new evidence.

## 4. Mandatory passes

### Pass A: scope reconstruction

- Read the base manuscript end to end.
- Identify the existing argumentative spine and the minimum changes needed.
- Reject a detached historical excursus.
- Reject any onomancy-to-Voynich mechanism claim.

### Pass B: conceptual rebuild

- Define operational inverse regimes without claiming an exhaustive ontology.
- Make the recovery object antecedent to the four evidential gates.
- Preserve the original empirical hierarchy.

### Pass C: empirical integration

- Add the complete compression-transfer negative calibration.
- Preserve Stage 1 and Stage 2 stop rules.
- State that no Voynich distance matrix was produced.
- Add compression rows to the cross-experiment table and synthesis.

### Pass D: historical integration

- Use the Sphere of Life and Death only as an attested many-to-one comparator.
- Mark the four-of-seven two-outcome result as an exhaustive derived count.
- Use Juste for notational transfer, not for Voynich similarity.
- Exclude Sigerist inversion claims, Burnett details, the unexplained +5, and unresolved Braekman metadata.

### Pass E: claim audit

- Verify all new numbers against the compression closeout.
- Check that the framework is explicitly non-exhaustive.
- Check every Voynich-specific inference for an explicit boundary.
- Run `verify_v04.py` and require `PASS`.

### Pass F: reference audit

- Verify DOI and bibliographic metadata for all added references.
- Separate the 2011 Juste article DOI from the 2012 erratum DOI.
- Record the remaining Chardonnens source-PDF checksum action.

### Pass G: hostile review

Review as if the paper were submitted by an unknown author. Search specifically for:

- taxonomy inflation;
- hidden promotion of historical analogy into target evidence;
- statistical overclaim from exhaustive table counts;
- generalisation from bounded compressors to all compression methods;
- conflation of recognition, proximity, recovery, and transfer;
- unsupported exclusion of historical cipher classes;
- archival claims exceeding available artefacts.

### Pass H: artifact verification

- Build Markdown, DOCX, LaTeX, and PDF.
- Compile LaTeX twice without fatal error.
- Render the DOCX to 50 page images and visually inspect all pages.
- Render the LaTeX PDF to 36 page images and visually inspect all pages.
- Run DOCX accessibility and style audits.
- Record SHA-256 hashes for all deliverables.

## 5. Stop rules

The revision must stop or narrow if any of the following occurs:

- a new empirical number cannot be traced to a frozen result;
- the historical material requires an unverified source for the central claim;
- onomancy is made to bear a Voynich-specific inference;
- compression failure is generalised beyond the registered programme;
- a build does not render cleanly;
- verifier status is not `PASS`.

# Supplement S6: Cross-Line Evidence — Worked Examples

Each word in the manuscript decomposes into four slots: Prefix + Gallows + Core + Suffix. The tables below trace consecutive words on real manuscript lines, showing which nearby word each token was derived from and which production rule was applied.

**Production rules (as described in §4.6):**
- **Rule 1:** Copy from recent work — pick one of the last few words on the current folio
- **Rule 2:** Change the suffix — most of the time, but not always
- **Rule 3:** Change at least one other slot — if no gallows or core, change the prefix
- **Rule 4:** Every ~5th word, draw completely fresh instead of copying
- **Rule 5:** At each new line, draw fresh

**Match notation:** 4/4 = exact copy; 3/4 = one slot changed; 2/4 = two slots changed; 1/4 or lower = heavy rewrite or fresh draw.

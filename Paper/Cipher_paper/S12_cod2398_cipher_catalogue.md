# Supplement S12: Cipher Key Catalogue from ÖNB Cod. 2398

## Bozzard, E. (2026). A Two-Table Cipher Architecture for Beinecke MS 408.

---

### 1. Source Manuscript

**ÖNB Cod. 2398**, *Furtivae litterarum notae, quibus usus fuisse videtur
in cancellaria Vicecomitum Mediolanensium 1450–1496*. Österreichische
Nationalbibliothek, Vienna. Barcode +Z22661150X.

The manuscript is the cipher register of the Sforza cancelleria segreta,
compiled principally by Nicodemo Tranchedino (chief secretary to the Duke
of Milan) from c.1475, with contributions in at least two hands. It
contains operational cipher keys used for diplomatic correspondence between
the Sforza court and its ambassadors, allies, and correspondents across
Italy and Europe. The manuscript comprises 357 digitised images
(approximately 180 folios recto/verso plus prefatory material).

Cerioni (1970) provides the most detailed published study of this
manuscript; Höflechner (1970) supplies commentary. The DECRYPT database
(Record #10155) catalogues the related Albertoni cipher ledger (BSCr, LC,
ms. Albertoni 97), a parallel Sforza cifrario held at the Biblioteca
Statale di Cremona.

### 2. Methodology

We examined the digitised images of Cod. 2398 and recorded the structural
features of each individual cipher key. A "cipher key" is defined as a
self-contained set of encipherment instructions assigned to a named
correspondent, typically occupying one folio recto or verso (occasionally
spanning a full opening). The catalogue covers folios 1r through 142r,
corresponding to 225 individual cipher keys dated between 1450 and 1494.

For each key, we recorded:

- **Folio number** and **date** (from the key's header inscription)
- **Correspondent** (the ambassador or official for whom the key was created)
- **Number of alphabet rows** (homophonic depth: how many distinct cipher
  symbols are provided per plaintext letter)
- **Syllabary** (presence/absence of a consonant-vowel substitution grid,
  i.e. systematic CV pairs such as ba, be, bi, bo, bu)
- **Geminate table** (presence/absence of dedicated symbols for double-letter
  pairs: bb, cc, dd, ff, etc.)
- **Null symbols** (presence/absence and approximate count)
- **Function word encoding** (presence/absence of dedicated cipher entries
  for high-frequency words such as *che*, *come*, *quando*, *non*, *per*,
  *perche*, *pertanto*, or Latin equivalents)
- **Nomenclator** (presence/absence and approximate entry count: dedicated
  cipher symbols for named entities — persons, places, institutions,
  military/diplomatic concepts)
- **Latin function words** (whether any function-word entries use Latin
  rather than Italian)

Alphabet row counts, nomenclator sizes, and null counts are approximate,
read from manuscript images at screen resolution. Some entries are partially
illegible; counts should be regarded as ±10% for nomenclator sizes above 30.

The catalogue was compiled in three batches:

| Batch | Folios | Keys | Date range | PDF pages |
|-------|--------|------|------------|-----------|
| 1 | 1r–41v | 83 | 1450–1465 | 1–100 |
| 2 | 42v–116v | 101 | 1465–1485 | 101–250 |
| 3 | 117r–142r | 41 | 1483–1494 | 251–300 |
| **Total** | | **225** | **1450–1494** | |

Pages 301–357 (approximately folios 143r–180v) were not catalogued in this
study. The prefatory section (folios 1–20 approximately) contains an index
in red ink and at least one historical cipher key predating the main
sequence (a 1408 Venetian cipher key at the front of the codex; see §2.1
of the main paper).

### 4. Comparison with VMS Architecture

| Feature | Cod. 2398 (n=225) | Beinecke MS 408 |
|---------|-------------------|-----------------|
| Two-table structure | 98% | Yes |
| Homophonic substitution | 97% | Yes (~4 prefix houses) |
| 4+ homophonic depth | 14% | Yes (4 houses) |
| Consonant-vowel syllabary | 28% | Yes (FC babuini grid) |
| Function word encoding | 76% | Yes (~11 EC function words) |
| Latin function words | 9% | Yes (pharmaceutical Latin) |
| Nomenclator | 98% | Yes (~11 entries) |
| Nomenclator size (median) | 30 | ~11 |
| Null symbols | 89% | No |

The manuscript's architecture falls within the standard range of Sforza
cancelleria practice on every dimension except null symbols (absent in the
VMS) and nomenclator size (~11 entries vs. a median of 30). The
nomenclator size difference is explained by genre: Sforza nomenclators
encode named political entities (Papa, Rex Aragonum, Dux Burgundie, etc.)
irrelevant to a pharmaceutical text. The absence of null symbols in the VMS
is discussed in §2.1 of the main paper.

### 5. Notable Individual Keys

**Closest structural parallels to VMS:**

- **Laurencio Mozanca** (fo. 126r, 15 August 1486): 4 alphabet rows +
  explicit 2D consonant-vowel grid + nomenclator with function words.
  Every architectural component of the VMS system except the Latin-language
  nomenclator, in a single key.

- **Gerardo Cerruto** (fo. 78v–79r, c.1480): 5 alphabet rows, full
  syllabary, 35 function-word entries, 70 nomenclator entries. Most
  elaborate key in the catalogue.

- **Nicodemo Tranchedino** (fo. 88v–89r, c.1478): 5 alphabet rows, full
  syllabary, 80 nomenclator entries. Tranchedino's own operational cipher.

**Closest Latin-nomenclator parallel:**

- **Johanne de Rabesten** (fo. 69v, 13 April 1472): Latin function words
  Quod, Autem, Quomodo, Quando, Quia, Non, Si, Vel. Cipher for
  correspondence with a counsellor to the King of Hungary, where Latin was
  the working diplomatic language.

**Earliest key in main sequence:**

- **Nicodemo Tranchedino** (fo. 1r, 25 October 1450): The Tristano Sforza
  key, with compound glyph 4o confirmed from primary image as enciphering
  *s*.

### 6. Data Availability

The full catalogue (225 keys × 17 fields) is provided as a CSV file:
`s12_cod2398_catalogue.csv`, deposited at Zenodo
(DOI: 10.5281/zenodo.18812705).

Column definitions:

| Column | Description |
|--------|-------------|
| id | Sequential key number (1–225) |
| batch | Cataloguing batch (1, 2, or 3) |
| folio | Manuscript folio number |
| date | Date from key header (as written) |
| year | Extracted year (numeric) |
| correspondent | Named correspondent or role |
| n_alpha_rows | Number of alphabet substitution rows |
| has_syllabary | CV syllabary present (True/False) |
| has_geminate | Geminate (double-letter) table present |
| has_nulls | Null symbols present |
| n_nulls | Approximate null symbol count |
| has_fw | Function word encoding present |
| n_fw | Approximate function word entry count |
| has_nomenclator | Nomenclator section present |
| n_nomenclator | Approximate nomenclator entry count |
| has_latin_fw | Any Latin function words present |
| notes | Free-text notes on key features |

# Voynich Walk — notes for an AI assistant working on this folder

A static website (no build step, no package manager). Three.js 0.160 and lil-gui are vendored in `lib/`.
Open it through a local web server (`start-windows.bat` / `start-mac.command`, or `python -m http.server`),
never from the file system: browsers block the textures and YouTube refuses to embed.

## Where things are
- `walk.config.js` — the content: stations (YouTube id, plants beside it, optional title/note/start/clip), title card, guide, plant notes. Most requests are edits here.
- `settings.js` — every number (spacing, camera, plant density, wind, video behaviour, tour speed, colours, recording).
- `youtube.js` — generated by `python tools/fetch_youtube.py` (channel feed + oEmbed for older ids; stdlib only). Do not hand-edit; rerun the tool.
- `assets.js` — generated by `python tools/make_asset_list.py` from `plants/` and `creatures/`.
- `js/main.js` loading, scrolling, tour, picking · `js/world.js` scenery, plant placement, frames, pond · `js/youtube.js` silent YouTube inside the active frame (CSS3D layer behind a see-through window in the WebGL canvas) · `js/guide.js` the guide and speech bubble · `js/ui.js` info card, video viewer, settings panel (G), recording.

## Rules that keep it working
- Keep every path relative (the site is served from a sub-path on GitHub Pages).
- The page is published by `.github/workflows/voynich-walk-pages.yml` in the parent repo whenever `voynich-walk/**` changes on `main`.
- Plants are cut-outs from Yale's scans of Beinecke MS 408 (Yale IIIF), named by folio (`plants/f12v.png`). Clicking one links to Yale's scan of that folio; keep that attribution.
- The walk is illustration, not interpretation: nothing on it should present a reading or decipherment of the text.
- After changes, check in a browser: the loader finishes, stations show their YouTube pictures, standing at a frame fades the video in (needs a web server and internet), clicking a plant opens its folio card.

## Common tasks
- New video: run `python tools/fetch_youtube.py`, copy the printed id into `stations` in `walk.config.js`.
- Reorder or remove stops: edit `stations`; spacing comes from `settings.js -> walk.stationSpacing`.
- Different guide: `guide.file` in `walk.config.js` (alternatives are listed there).
- New cut-outs: PNG with transparency into `plants/` or `creatures/`, then `python tools/make_asset_list.py`.
